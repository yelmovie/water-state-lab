# 놀이 화면 비율·중복 조작 정리 · 2026-11-18

기준: `../_shared/LAYOUT-BALANCE-DELIVERY-20261118.md` 1·2절. 세 뷰포트(1280×800, 1024×768, 1920×1080)에서 화면마다 놀이 영역의 높이·면적·빈 띠·중심 위치와 보이는 조작 요소를 JS로 뽑았다. 측정 스크립트는 `.tmp/layout-balance-20261118/measure.mjs`, 변경 전 수치는 운영 주소(`before/`, `before-ending/`), 변경 후 수치는 로컬 개발 서버(`after/`, `after2/`)에서 얻었다.

놀이 영역으로 잰 요소: 실험·현장 `.activity-area`, 지도 `.map-viewport`/`.journey-world`, 3D 런 `.run-stage canvas`, 결과 화면 `.ending-main>*`(그림 카드+버튼 열), 타이틀 `.start-copy`.

결과 화면 원인: `guided-experience.css`의 넓은 화면 규칙이 `.ending-main`을 `grid-template-rows:auto; align-content:center`로 두고, 그림 카드에 `contain:size; height:100%`를 걸었다. 그래서 두 칸이 버튼 열의 높이만큼만 커져 화면 가운데의 낮은 띠에 놓였다.

타이틀 예외: 왼쪽 `.start-copy`(제목·버튼)만 잰 값이다. 오른쪽 띠는 방울이와 연구섬 그림이 차지하는 타이틀 장면이라 빈 배경이 아니다(기준 1절 "장식 그림이 의미 있는 장면" 예외). 바꾸지 않았다.

## 3. 수정안과 채택

| 안 | 채택 | 이유 |
|---|---|---|
| 결과 화면 두 칸이 위 띠 아래 높이를 다 쓰게(`grid-template-rows:minmax(0,1fr)`, 그림 카드 `contain` 해제, 1920 폭 상한 1680px) | 채택 | 기준 1절 방법 1. 배치(그림 왼쪽·글과 버튼 오른쪽)는 그대로 |
| 결과 화면 다시 보기 2개·교실 장치 1개를 글자 버튼(밑줄)으로 낮춤 | 채택 | 기준 2절 "같은 무게" → 주 버튼 1개만 진하게. 터치 높이 44px 유지, 키보드 초점 유지 |
| 지도 현재 섬 이름표의 「→」 제거 | 채택 | 진짜 출발 버튼은 오른쪽 아래 하나. 이름표는 강조 색과 눌러서 걸어가기를 그대로 유지 |
| 「100mL 붓기」「얼음틀에 물 붓기」 버튼 제거 | 미채택 | 안내 문구가 버튼을 부르고, 끌기가 어려운 학생의 대체 경로다 |
| 결과 화면 주 버튼을 오른쪽 아래로 이동 | 미채택(제안) | 글·버튼 열 구조 자체를 바꾸는 재디자인. 지금은 첫 칸·노란 강조라 한눈에 보인다 |
| 현장 4(이슬 정원)의 물통을 1920에서 더 크게, 「담은 물/권장 70」 숫자 한 곳으로 | 미채택(제안) | 영역 비율은 통과. 숫자 표시는 학습 판정 화면과 엮여 있다 |
| 현장 2(얼음틀) 1920 위쪽 빈 공간 줄이기 | 미채택(제안) | 영역 비율 통과(98.5%). 장면 안 배치 조정은 별도 디자인 작업 |

구현은 새 파일 `src/layout-balance.css` 하나와 `index.html`의 연결 한 줄이다. 학습 문구·판정·저장·진행 코드는 건드리지 않았다. 다른 세션이 작업 중이던 `experience.css`도 고치지 않았다.

## 6. 남은 제안 반영 · 2026-11-19
