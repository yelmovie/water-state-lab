## 3D를 넣은 곳과 이유

- 9장 `3D로 보기`: 학생이 놓은 부품 위치·기울기를 1px=1mm로 그대로 조립한다. 시험에 성공한 물길이면 물방울이 흐른다.
- 10장 `3D로 보기`: 고치는 중인 장치와 물방울 코어. 물이 도착하면 코어가 빛난다.
- 엔딩 `연구섬 3D로 둘러보기`: 연구섬 디오라마와 물레(바퀴 회전).
- 모두 선택형이다. Three.js와 모형은 열 때만 받고, WebGL이 없거나 실패하면 2D로 계속한다. 움직임 줄이기에서는 자동 회전을 멈춘다.
- 모형 다듬기: 용접 → 복셀 재구성 → 삼각형 줄이기 → 새 펼침 좌표에 원본 바탕색 굽기. 처음 방식(바로 줄이기)은 물통이 찢어지고 금색이 어두워져 버렸다. 증거: `_scratch/waterchange-3d/renders/`.
