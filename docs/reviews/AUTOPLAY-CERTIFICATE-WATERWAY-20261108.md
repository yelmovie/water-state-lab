# 자동재생·인증서·연구섬 수로 적용 기록

2026-11-08 1차 적용 기록. 이후 자동 관찰·주민 5명·Sohee 교체 결과는 [후속 기록](GUIDED-NPC-SOHEE-20261108.md)을 따른다. 아래 NPC 10명 표와 음성 후보는 1차 작업 당시 상태다. 외장 T7 Shield의 소스에 적용. 학생 저장 기록을 건드리지 않는 별도 브라우저 컨텍스트에서 확인했다.

## 적용 내용

- 본 실험 1–10과 현장 실험 2·4·10에 자동재생 버튼을 표시한다. 관찰·기다리기·기록·장치 이동은 기존 조작을 재사용한다.
- 예상, 분류 답, 설명 순서, 고장 원인, 물의 양과 이유, 완료·보상은 학습자가 고른다. 선택이 필요한 지점에서는 자동재생이 멈춘다.
- 직접 터치·키보드·입력·휠 조작과 화면 숨김에서 자동재생을 멈춘다. 측정 시계, 시험관 이동, 얼음틀, 상태 변화 과정, 한파·온실 시계의 진행 중 애니메이션도 취소하거나 일시 정지한다.
- 장 진입 시 자동 시작 편지, 현장 의뢰 편지와 중간 주민 인사 팝업을 열지 않는다. 필요한 안내는 화면에 표시하고 편지는 사용자가 눌러 다시 볼 수 있다.
- 지도 상단의 ‘마을 수첩 10/10’ 버튼과 별 아이콘을 제거했다.
- 파이널 영상의 원형 응결판을 참고해 새 투명 에셋을 생성했다. 마른 판·냉각·물방울·받이·모인 물을 단계별로 합성한다. 최적화 WebP 63 KB, 생성 PNG·프롬프트·해시는 외장 SSD `assets/source-media/ending-collector-20261108/`에 보존한다. 검증한 이번 생성 내장 임시 원본만 삭제했다.
- 연구 인증서의 학교·반·번호·이름은 출력 후 손으로 쓰는 네 빈칸이다. 입력창과 개인 정보 저장을 추가하지 않았다. 붉은 연구 인증 도장과 기존 금색 인증 마크를 함께 배치했다. A4 가로·10 mm 여백에서 인쇄 컨테이너의 추가 패딩과 폭 제한을 제거했다.
- ‘되살린 연구섬’ 3D의 물레 받이에서 온실 아래 마을 물길까지 열린 U자 수로, 황동 출수구·테두리, 두 석재 교각과 기초를 연결했다. 물레 기초를 12 mm 올려 전 구간이 내리막이 되도록 했다. 실제 GLB 표면을 레이캐스트한 합류 지점 높이는 약 0.05058 m이며, 최종 물은 0.0508 m에서 닿는다. 새 GLB·텍스처·의존성은 추가하지 않았다.

## 검증

- `npm run check`: 소스 문법 검사 통과.
- `npm test`: 204개 통과, 0개 실패. 수로 연속성·내리막·마을 합류 지점과 물레 이동 시 출수구 정렬을 포함한다.
- 12개 화면 크기 × 지도·본 실험 10개·현장 3개 × 힌트 닫힘·열림 = 336개 상태: 수평 넘침·힌트 겹침·가림·관련 화면 밖 조작 0건, 브라우저 오류 0건. `tmp/hint-responsive-current/report.json`.
- 자동재생: 전체 버튼 표시, 자동 진입 팝업 제거, 예측·분류·설명·진단 선택 경계, 시계 정지, 이동 중 시험관 취소, 현장 실험 관찰 19개 확인 통과, 브라우저 오류 0건. 최신 전체 결과는 `tmp/all-autoplay-qa-20261108/report.json`.
- 인증서 화면·인쇄 미디어와 응결판 상태를 시각 확인했다. A4 가로 내용 영역 상당의 1047×719 CSS px에서 인증서와 인쇄 본문은 모두 1047×718.11 px이며 추가 패딩이 없다. `tmp/visual-changes-20261108/`.
- 3D 수로는 정면·위쪽에서 합류와 지지를 확인했다. `tmp/island-connection-20261108/after-front.png`, `after-top.png`. 실물 태블릿 성능 측정은 수행하지 않았다.
- 최종 빌드에 새 응결판 에셋과 오프라인 캐시 항목이 포함된다. `dist/`는 외장 SSD에만 생성한다.
- AST 그래프를 `graphify update .`로 갱신했다.
