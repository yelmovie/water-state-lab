# 9·10장 컬러 피겨스 — 2026-11-06

- 9장 **내 물방울 길 보기**는 첫 시험 뒤에 열린다. 현재 시험 중인 배치를 바꿔도, 새로 시험하기 전까지는 마지막으로 시험한 배치와 결과를 보여 준다. 냉각판부터 물통까지 부품을 누르면 이름과 하는 일이 보인다.
- 10장 **두 고장 비교하기**는 장치를 시험하고 고장 원인을 하나 고른 뒤에 열린다. 예시 A에서는 물방울이 맺히지 않는다. 예시 B에서는 물방울이 맺히고, 경사판과 받는 부품의 틈에서 물이 바닥으로 샌다. 두 예시는 해당 학생의 고장과 별개이며 진단·보상·저장값을 바꾸지 않는다.
- 손가락으로 직접 돌리거나 큰 회전 버튼을 쓸 수 있다. 속 보기로 깔때기·연결관·물통의 벽을 투명하게 보고, 부품 확대와 처음 각도로 돌아가기를 지원한다. 움직임 줄이기에서는 애니메이션 대신 정지 장면을 순서대로 보여 준다. 닫기와 실험 복귀는 각 화면의 위와 아래에 있다.
- 벡터 모형은 청록색·황동색·크림색으로 구성했다. [Colorfigures](https://april-zhu.com/colorfigures)의 MIT 엔진으로 투영·면 음영·윤곽선을 그리며, 앱의 기본 실험이나 WebGL에 의존하지 않는다. [미국 지질조사국의 응결 자료](https://www.usgs.gov/water-science-school/science/condensation-and-water-cycle?page=1)와 실험 모형을 참고했다. 수증기 자체는 그리지 않고 눈에 보이는 액체 물방울부터 표시한다. 실제 수집량을 예측하는 모형은 아니다.

검증 크기: 1920×1080, 1024×600, 768×1024, 915×412, 390×844. 전체 회전에서 겉모습과 속 보기의 SVG 범위를 확인했고, 터치 회전·부품 선택·확대·재생·단계 보기·닫기·복귀를 확인했다. 10장 두 예시의 물방울 유무와 새는 경로를 각각 검증했다. 실제 학교 장비는 연결되어 있지 않아 Chrome의 뷰포트와 터치 입력으로 확인했다.

브라우저 16개 기존 실험 흐름과 자동 테스트 104개 통과. 배포용 빌드 성공. 캡처와 브라우저 검증 기록은 SSD의 `.tmp/visual-qa/colorfigures-20261106/`에 있다.

## 모형 크기와 물길 표시 개선

- 조작 도구를 옆에 두고, 모형은 실제로 그려진 범위를 기준으로 빈 여백을 줄였다. 1024×600에서 그리는 칸이 기존 198px에서 408px로 커졌다. 작은 화면의 닫기와 돌아가기는 계속 고정된다.
- 물방울을 크게 표시했다. 이미 지나간 길에는 파란 실선과 진행 방향, 새는 길에는 주황 점선과 ‘새는 곳’ 표식을 남긴다. 물이 안 맺히는 경우에는 경로와 물방울을 표시하지 않는다.
- ‘자동재생’은 시작·일시정지·이어 재생을 지원한다. ‘한 단계씩’은 언제든 별도로 쓸 수 있다. 움직임 줄이기 상태에서도 자동재생을 직접 누르면 정지 장면을 차례대로 보여 준다.
