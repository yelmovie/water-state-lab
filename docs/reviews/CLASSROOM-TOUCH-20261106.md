# 태블릿·전자칠판 글씨와 터치 점검 — 2026-11-06

[11월 5일 전체 점검](RELEASE-REVIEW-20261105.md)의 가독성·터치 후속 점검이다. 브라우저의 뷰포트와 터치 입력으로 확인했다. 실제 학교 장비에서의 뒷자리 가독성, 밝기와 터치 보정은 이 결과에 포함하지 않는다.

| 대상 | 확인한 화면 크기 |
|---|---|
| 전자칠판 크기 | 1920×1080, 1536×864 |
| 태블릿 가로 | 1280×720, 1024×768, 1024×600 |
| 태블릿 세로 | 768×1024 |

홈·지도·엔딩과 1~10장 실험·현장 의뢰를 합쳐 23개 상태를 여섯 크기에서 검사했다(138화면). 표본 화면의 표시 중인 조작 요소에서 48px 미만, 글자 잘림, 가림, 가로 넘침이 없었다. 검사한 DOM 글씨는 1920·1536 폭에서 18px, 나머지에서 14px 이상이었다. 세로 화면은 실험판과 도구를 위아래로 배치하고, 이어지는 도구는 세로 스크롤로 볼 수 있다. 캔버스 안 조작은 아래처럼 별도로 시험했다.

| 실제로 보인 문제 | 바꾼 동작 |
|---|---|
| 넓은 화면의 ‘지금 할 일’, 도구 보조 설명, 지도 표식이 16~17px에 머묾 | 큰 화면에서 18px 이상으로 올리고, 세로 태블릿에서도 2장 전후 설명을 14px 이상으로 유지했다. |
| 일부 지도·안내 버튼과 실험 슬라이더가 40~45px | 클릭·터치 영역을 48px 이상으로 확보했다. 가열·수위·기울기·밸브 손잡이 그림을 크게 표시했다. |
| 예상선과 수위 손잡이의 원 안쪽만 잡힘 | 원 바깥에도 손가락이 조금 닿아 있으면 잡히도록 했다. 물길 잇기의 이웃 부품 중에는 터치 지점에 가까운 쪽을 선택한다. |
| 1024×600에서 10장 증거 버튼이 아래에서 잘리고, 코어 연결 후 밸브가 앞 단계 도구에 밀림 | 원인·증거를 가로로 배치했다. 연결 뒤에는 밸브와 ‘물 보내기’를, 물 도착 뒤에는 레버를 도구판 위에 표시한다. |
| 터치 화면 지도에서 키보드로만 조작하라는 안내가 나옴 | 화면 화살표와 장소를 눌러 이동하도록 안내하고 키보드도 그대로 지원한다. |

Chrome의 터치 입력으로 1024×600·1024×768·1920×1080에서 예상선, 물높이, 경사판 가장자리, 인접한 물길 부품, 10장 증거·밸브·레버를 확인했다(18건). 현장 의뢰와 저장·완료를 포함한 기존 브라우저 경로 16개, 자동 테스트 102개, 배포용 빌드가 통과했다. 운영 배포는 하지 않았다.

캡처와 측정 원본은 SSD 작업 폴더 `.tmp/visual-qa/classroom-20261106/`에 있다. `final.json`은 크기별 화면, `touch-results.json`은 터치 조작, `expedition/`은 실험 경로 증거다.

## 컬러 피겨스 적용 후보

1. **9장 공방의 ‘물방울 길 보기’** — 첫 설계 시험 뒤에 여는 선택 자료. 돌려 보기로 장치를 살펴보고, 투명 보기로 냉각판에 맺힌 물방울이 경사판 → 깔때기 → 연결관 → 물통으로 이동하는 과정을 본다. 기존 3D의 장치 모양 보기에 관찰 기능을 보탠다.
2. **10장 코어 복구** — 학생이 원인을 먼저 고른 뒤, 투명 보기에서 판에 물방울이 생기지 않는 경우와 이미 생긴 물이 연결부에서 새는 경우를 비교한다. 실험 전에 답을 드러내지 않는다.

두 후보는 이번 가독성·터치 수정에는 넣지 않았다.
