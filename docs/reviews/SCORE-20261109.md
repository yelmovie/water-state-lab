화면 유형: 교육용 게임 UI + 게임 플레이 화면. 일러스트 배경이라 금색 버튼·따뜻한 톤은 **게임 화면 예외(4-1)** 로 본다.

| 항목 | 결과 | 근거 |
|---|---|---|
| 반응형 | 통과 | 4해상도 가로 스크롤 0, 버튼 가림은 지도 라벨 1곳 |
| 대비 | 일부 확인 | 본문·버튼은 진한 글자 + 흰 판. 지도 위 작은 라벨은 대비 측정 안 함 |
| 키보드 | 통과 | 포커스 표시 좋음. 영상 대화상자는 `showModal()`(오탐 정정) |
| 모션 | 통과 | reduced-motion 규칙 26개, 관찰 속도 조절(0.25~2배) |
| 정지 가능 | 통과 | 자동 관찰 '관찰 멈추기' 버튼, 영상 건너뛰기 |

| 토큰 | 남은 문제 | 하드코딩 색 1,509곳, CSS 12파일에 `:root` 17곳으로 흩어짐 |
| 톤 | 통과 | 타이틀·지도·실험 화면 모두 수채 일러스트 톤과 UI가 맞음 |
