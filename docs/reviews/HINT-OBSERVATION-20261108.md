# 힌트 반응형과 관찰 화면 개선 · 2026-11-08

## 변경 내용

- 지도 힌트 말풍선을 방향키 위로 펼치고, 좁거나 낮은 실험 화면에서는 방울이 힌트를 별도 줄에 배치했다. 힌트창은 홈·뒤로 버튼 아래의 화면 안에서 스크롤한다.
- 4장 실험용으로만 쓰는 짧은 화면 배치가 한파 의뢰에 적용되어 화면과 힌트가 위로 밀리던 선택자를 제한했다. 작은 화면의 물 양 조절 버튼도 각 실험 칸 안에 맞췄다.
- 닫힌 냉동고 2종과 쭈쭈바의 얼리기 전·얼어 부푼 뒤 이미지 2종을 기본 OpenAI imagegen으로 생성했다. 2·3장에서는 실제 닫힌 그림으로 교체하고, 3장 쭈쭈바는 같은 크기의 두 그림으로 비교한다.
- 4장 냉동고 이미지·선반·시험관을 동일한 600×545 좌표계에 배치했다. 시험관이 현재 위치에서 내부 선반으로 이동하고, 문이 닫힌 뒤 얼고, 다시 문을 열어 비교 선반으로 이동한다. 장면을 나가면 이동 복제본과 예약 동작을 정리한다.
- 4장 자동재생은 기존 물 양 조절·얼리기 버튼을 사용해 두 조건을 비교한다. 빈자리 선택과 다음 활동 진행은 사용자가 한다. 수동 조작과 재생 버튼으로 자동재생을 멈출 수 있다.
- A 붓 자국은 가늘고 진하게, B는 넓고 옅게 표현했다. 실시간 Canvas와 기록 SVG에 같은 선 스타일을 적용하고, 건조 시간과 기존 관찰 기록 구조는 유지했다. 붓 그림의 폭도 구분했다.
- 6장 A 비커의 ‘실온 받침’ 상자·문구와 대체 SVG 받침을 제거했다.
