# 이미지 로딩 복구 · 2026-10-25

- 원인: 4324 포트의 로컬 서버가 종료되어 이미지 요청이 연결 거부됨. 기존에 열린 화면에는 캐시된 코드만 남았고, Phaser는 없는 도구 텍스처를 초록색 오류 사각형으로 표시함.
- 복구: 프로젝트 폴더에서 4324 서버를 별도 숨김 프로세스로 재실행하고 기존 게임 탭을 새로고침함. 현재 학생의 관찰 시간 100과 활동 진행이 유지된 것을 확인함.
- 수정: `src/phaser-scenes.js`에서 이미지 로딩 실패 시 캔버스로 전환하지 않고 기존 DOM 실험과 조작 버튼을 유지함.
- 검증: 직접 참조 이미지 13개 HTTP 200·디코딩 성공. 문법 검사·빌드 통과. 현재 실험 배경과 천 그림 복구 확인. 도구 이미지에 의도적으로 404를 반환한 별도 4326 테스트에서 오류 캔버스가 없고 기본 그릇·물 붓기가 작동함을 확인함. 테스트 서버와 탭은 정리함.
- 증거: `screenshots/image-load-fix-20261025/restored.png`, `fallback.png`.
