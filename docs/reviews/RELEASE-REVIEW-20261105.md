# 최종점검 — 방울이의 물길 탐험

**조건부 배포 가능.** 로컬 구현과 빌드에서 학습·저장·완료를 막는 문제가 재현되지 않았다. 이번 작업 트리는 아직 공개 배포하지 않았다. 학교 기기에서의 학습 시간과 터치, 기존 제공 영상·음원 이용 범위 확인을 배포 조건으로 둔다.

- 작업 기준: `83fcd2f`, 사용자 변경이 있는 작업 트리를 유지했다. 전체 해금으로 열었던 관찰은 학생 저장값에 기록되지 않는다.
- 실행: `npm run check`, `npm test` 102개 통과, `npm run build` 통과. 배포용 빌드의 4317 포트와 개발 4316 포트, 기존 공개 주소를 분리했다.
- 화면: 1280×800·1920×1080·1024×768·915×412·390×844에서 25개 상태를 수집(125개). 자동 검출 가로 넘침·가림·잘림·깨진 그림·작은 글자(13px 미만)·페이지 오류 0. 모든 버튼 48px·캔버스 레이블 18px를 재는 검사는 아니다.
- 조작: 현장 의뢰 10개를 포함한 브라우저 흐름 16개 통과. 캔버스 물그림 저장, 교사 시연 분리, 초기화, 두 가지 코어 고장과 엔딩 새로고침을 포함한다. 주입한 오류 요청 3건 외 예상하지 않은 네트워크/HTTP 오류 0.
- 미디어: 개념 영상 MP4·WebM 각 10편과 10개 장면 선택·동작 줄이기·닫기 경로를 Chrome에서 확인했다. 영상 재생을 눌렀을 때 뒤의 실험이 동시에 눌리던 문제를 고쳤다. 소리 파일 7개, 모달 15개, 터치로 옮기기와 선 잇기, 영상 실패 시 설명 대체, 두 번째 방울이 단서를 여는 동작도 별도 회귀 검사에서 통과했다.
- 첫 화면: 새 로컬 Chrome 컨텍스트 940ms, 885ms, 881ms, 2,698,263바이트. 서비스 워커 활성화 후 오프라인 상태에서 타이틀 새로고침 성공. 새 실험 WebP 합계 110,902바이트.
- 근거: SSD 내부 프로젝트의 `.tmp/visual-qa/final-sweep/sweep-last.json`, `.tmp/visual-qa/expedition-verified/expedition-flow-results.json`, `.tmp/visual-qa/postcheck-results.json`, [이미지 출처와 프롬프트](ASSET-UPDATE-20261105.md). 브라우저 수치는 실제 전자칠판·학교 Wi-Fi 수치가 아니다.

1. 담당 교사가 실제 4학년 수업에서 대표 학생의 첫 5초 행동 이해, 25~30분 플레이, 예상과 근거 설명, 전자칠판 뒤에서 읽히는지를 확인한다(A6·A12·B16·C20·C23).
2. 학교 태블릿의 화면 회전·가장자리·멀티터치·확대, 느린 Wi-Fi 및 사전 오프라인 준비, 선택 3D와 인증서 인쇄를 실기기에서 확인한다(C3·C19·C25·D4·D9~D11·G19).
3. 기존 제공 도입·엔딩 원본과 생성 음악 사용 조건을 제작 담당자가 CREDITS 근거와 대조한다(F10·F12). 새 배포 후 실제 학생 URL·OG·카카오톡 표시와 1장 저장/재방문을 확인한다(G7·G11·G12·G18).
4. 큰 모듈과 장별 교육 메타데이터 분리, 전수 미사용 자산 검사는 유지보수 항목으로 기록했다(A11·D5·D6·E2·E3).

배포 또는 운영 상태 변경은 수행하지 않았다.
