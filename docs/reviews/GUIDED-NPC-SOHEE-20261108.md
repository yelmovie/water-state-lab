# 건물별 자동 관찰·큰 실험 화면·Sohee 적용

2026-11-08. 작업·모델·임시파일·빌드·검증 로그는 실제 USB 외장 T7 Shield에 저장했다. 로컬 개발 주소는 http://127.0.0.1:4316/ 이며 배포하지 않았다.

## 최종 동작

- 건물 5곳에 실험 2개씩 묶었다. 지도에서 별도 주민 표식과 대화 진입을 제거하고 건물 주민 5명만 안내한다. 기존 홀수 단계 방문·완료 기록은 같은 건물 주민으로 호환하며 삭제하지 않는다.
- 상단에 짧은 안내, 건물 안 실험 탭, 작은 시계가 있는 관찰 버튼, 방울이 힌트와 직접 조작 버튼을 배치했다. 실험 그림이 화면 대부분을 사용한다. 질문은 옆 패널, 좁은 세로 화면에서는 그림 아래에 표시한다.
- 기본은 자동 관찰이다. 준비·도구 이동·기다리기·기록·실험 연결은 자동으로 진행하고 예상·분류·설명·원인 질문에서 멈춘다. 답변 뒤 자동으로 이어진다. 중간 장 시작/주민/개념영상 팝업은 강제하지 않고 안내와 복습으로 접근한다.
- 직접 터치·키보드·입력·휠 조작 시 자동 관찰을 멈춘다. 같은 페이지를 다시 그려도 정지를 유지하고 관찰 버튼으로 이어갈 수 있다. 완료한 방문을 자동으로 다시 보상하지 않는다.
- 물 컵의 입구에서 얼음틀의 실제 여섯 칸까지 물줄기가 닿는다. 컵의 물이 줄어드는 양과 채운 칸의 양이 맞는다. 컵 기울기에 따라 수면을 보정하고, 중간 정지·새로고침 시 부은 양을 보존한다. 같은 얼음틀이 냉동고 선반으로 이동하고 문을 닫은 뒤, 얼리고 꺼내 비교한다.
- 한파 실험은 통을 크게 보여 주고 낮·밤을 작은 배지로 표시한다. 마지막 질문에서도 세 통을 비교할 수 있다. 질문 버튼의 hover 1px 이동으로 생기던 경계 진동을 제거했다.
- 3·4구역은 새 완료 기록으로 설정의 복습 영상도 해금한다.

## 음성

모모를 통하지 않고 Qwen3-TTS CustomVoice / Sohee Python API로 대사 23개를 직접 생성했다. 캐릭터별 자연스러운 연기 지시를 적용하고 Apple AVAudioUnitTimePitch로 소폭 피치·속도를 보정했다. 브라우저 playbackRate만 변경하는 방식이 아니다.

| 주민 | 피치 cents | 속도 |
| --- | ---: | ---: |
| 파랑 | +100 | 1.04 |
| 뚝딱 | -100 | 0.99 |
| 보리 | -40 | 0.97 |
| 송이 | +40 | 1.00 |
| 느티 | -140 | 0.94 |

실행용 23개 MP3는 `public/assets/audio/npc-sohee-20261108/`에 있다. 원본·보정 WAV, 프롬프트, 모델 revision, 해시·파형 결과는 `assets/source-media/npc-qwen-sohee-20261108/`에 보존했다. 기존 음성 원본은 덮어쓰지 않았다. 도구는 `/Volumes/T7 Shield/tools/voice-alternatives/`, 모델은 `/Volumes/T7 Shield/tools/tts-models/`에 있다. Azure SDK는 준비되어 있으나 인증 정보가 없어 Azure 음성은 생성하지 않았다.

개별 보정본에 대해 사람이 청취한 자연스러움 평가를 수행하지 않았다. 사용자가 선택한 Sohee 음색을 적용했고 기술적 파형·재생 검증을 완료했다.
