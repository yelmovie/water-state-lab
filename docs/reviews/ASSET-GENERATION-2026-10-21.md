# 물길 탐험 새 이미지 제작 기록

2026-10-21, OpenAI 내장 이미지 생성 도구. 생성 결과를 직접 보고 적용했다. 사용자 제공 방울이 포즈와 연구섬을 참조해 색·캐릭터를 맞췄다. 아래는 제작 요청의 요약이며 원문 프롬프트의 완전 전사가 아니다.

| 파일 | 요청 요약·참조 | 사용 위치 | 원본 / 실행본 |
|---|---|---|---|
| story-repair | 16:9 어린이 과학 탐험 섬. 같은 방울이가 앞쪽 끊긴 수로를 돋보기로 조사하고, 멈춘 물레·시든 식물·다섯 연구 구역이 길로 연결된 장면. 글자·버튼·UI 없이. buddy-poses와 research-island-v3 참조 | 첫 도입·설정에서 도입 다시 보기 | PNG 3,090,019 B / WebP 466,248 B |
| rescue-reward | 같은 파란 물방울 연구원이 복구한 황동·청록 물레 코어를 기쁘게 보여 주는 단일 보상 일러스트. 완전 투명 배경, 글자·UI 없이 | 엔딩의 복구 보상 | PNG 1,690,922 B / WebP 291,550 B |

두 PNG는 `public/assets/v2/`에 보존했고 실행에는 같은 이름의 WebP만 사용한다. 투명 보상은 alpha 0~255 범위를 확인했다. 생성 원본의 로컬 식별자: `exec-55abfd59-9b5e-4c5c-8c10-36d47accce94.png`, `exec-4086b000-1ca5-490d-8928-0b57ea2e6c59.png`. 도구의 원본 반환 후 프로젝트 D: 폴더로 옮겨 실행본을 만들었다.

도입 그림의 주변 폭포에는 물이 흐르므로 사건 문구는 ‘섬 전체의 물이 멈춤’이 아니라 **연구실로 가는 물길**의 고장으로 제한했다. 보상 그림은 이야기용이며 물 수집 장치의 과학적 제작도로 사용하지 않는다. 실제 증발·응결 조건과 설계 시험은 별도 상호작용 모형이 담당한다.

같은 화풍의 기존 도구·방울이 이미지를 재사용했다. 컵·도구를 화면 장식용 CSS 도형으로 새로 늘리지 않고 비커 아틀라스에 상태에 따른 물높이·기포·물방울을 얹었다. 시계·화살표·별 등 기능 기호는 SVG/Canvas 벡터다. 생성 아이콘은 추가하지 않았다.

Jua의 한국어·라틴 WOFF2는 사용자 기준 프로젝트의 로컬 파일과 SHA-256이 일치한다. SIL OFL 1.1 전문을 동봉했다. 외부 이미지·폰트·음원 요청은 최종 빌드 검사에서 0이었다. 기존 사용자 제공 이미지의 상업 배포 권리 확인은 별도로 남아 있다.
