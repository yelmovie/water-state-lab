# Waterchange 고도화 적용 기록

## 범위와 보존
로컬 6 waterchange만 수정했다. 완료작 1~5와 다른 프로젝트는 수정하지 않았다. 커밋·배포·설치는 하지 않았다. 시작 시 이미 있던 NPC 모모 음성 33개, 실험 소품 그림, core-transfer, 현장 의뢰 축소 등 대량 미커밋 작업을 보존했다. 이번 수정 전 소스 복사본은 tmp/upgrade-backup-20261107-214950에 있다. 삭제 작업은 하지 않았다. 이미지와 음성 자산은 제품에 사용 중이므로 임시 생성물로 오인하여 지우지 않았다.

## 실제 적용한 개선 프롬프트
“완료작의 조건 비교 중심 학습, 첫 기록 보존, 직접 조작과 자동 관찰 구분, 48px 터치 원칙을 유지하라. 학생의 기존 물 수집 장치 위치와 시험 기록을 읽을 때 초기화하지 마라. 9장에서 빠르게 세 조건을 조작해도 비교 기록이 누락되어 막히지 않도록 실제 초기 모형 조건을 출처와 함께 보관하고 수동 시험 경로를 제공하라. 모션 줄이기는 애니메이션만 줄이고 읽기 시간을 줄이지 마라. 10장 진단은 냉각/연결 두 문제를 모두 낼 수 있게 하되 생성한 문제는 유지하라. 기존 그림·음성·현장 의뢰 축소·코어 높이 조작을 보존하고 회귀시험으로 검증하라.”

## 발견과 수정
- P1 재현: 기본 좌표와 다른 유효한 냉각판을 저장하면 재로딩 시 장치 전체와 시험이 초기화됐다. src/state.js:58의 좌표 기반 초기화 삭제. 비기본 좌표와 시험 기록을 그대로 읽는 회귀시험 추가.
- P2 재현: 자동 시험 900ms보다 빠르게 냉각·경사·깔때기를 고치면 성공 1회만 남아 비교 조건 때문에 출발이 막혔다. src/workshop.js:64에서 최초 조작 직전 실제 모형 결과를 source=initial-model로 보관. 더 살펴보기에 자동 기록 안내와 수동 시험 버튼 추가. 네 번의 빠른 연속 액션으로 완료 가능함을 시험.
- P2 재현: 모션 줄이기를 켜면 모든 자동 관찰 대기가 150ms로 줄었다. src/stage-assist.js:101에서 기존 관찰 시간을 유지. 타이머 지연값 회귀시험 추가.
- P2 재현: 성공한 깔때기 x=420에 따른 홀짝 분기는 냉각 고장만 선택했다. src/collector-model.js:18에 두 유형 선택 함수를 분리하고 src/workshop.js:35에서 최초 진단 생성 때만 적용. 난수 양끝에서 각 유형 생성 시험.
- 저장된 성공 1회 기록은 조작 안내가 잘못 깔때기만 지목하지 않도록 src/stage-guide.js에 조건 비교 안내 추가.

## 단계 중복 및 학습 역할
현재 1 상태 관찰 → 2 생활 분류 → 3 얼기/녹기 정량 비교 → 4 팽창을 고려한 용기 → 5 증발 물그림 → 6 비가열/가열 비교 → 7 응결 대조실험 → 8 증거 설명/전이 → 9 물 수집 설계 → 10 고장 진단/높이·밸브 전송으로 역할이 구분된다. 현장 의뢰는 이미 2·4·10 세 곳만 남아 있어 추가 삭제하지 않았다. 2장의 네 상태변화 연결과 마지막 순환 회로는 일부 반복되지만 처음의 분류와 끝의 증발·응결 회수 적용이라는 목적 차이가 있다. 반복 수를 늘리거나 예상 오답에 실패 벌점을 추가하지 않았다.
9장의 초기 자동 모형 결과는 직접 관찰을 했다는 증거가 아니다. 안내에서 출처를 공개하며, 성취 해석은 안내가 있는 조건 비교 활동으로 제한해야 한다. 10장의 근거는 원인 선택에 연결되어 자동 설정되므로 독립적인 근거 선택 평가라고 주장하면 안 된다.

## 그림·음성
앞선 반응형 보강의 기존 스테이지 배경/부품 그림/부품 이름 DOM/저높이 레이아웃을 유지했다. 현재 새 실험 소품 이미지와 모모 NPC 음성 33개가 실제 문구와 대응함을 tests/npc-content.test.mjs로 확인했다. 이미 충분한 자산이 있어 중복 이미지·음성을 추가 생성하지 않았다. 기존 Kenney 효과음과 메인/엔딩 음악, BGM/SFX 분리, 음성 중 BGM 정지, 숨김/대화 종료 시 음성 정리를 소스 확인했다. 이번 회차에서 실제 청취 품질이나 iPad 오디오 디코딩을 검증하지 않았다.

## 검증
