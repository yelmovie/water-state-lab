# 물방울 연구실 화면·개념 영상·상호작용 개편

2026-10-22. 기존 10단계 실험과 현장 의뢰, 학생 저장 기록·판정·교사 시연 구분을 유지하며 적용했다. 외부 배포는 하지 않았다.

## 적용 내용

| 영역 | 변경 |
|---|---|
| 발견 영상 | 단계별 9초 모션 그래픽 10편. 현장 해결 → 개념 영상 → 도장·기존 다음 활동 순서. 먼저 정답을 보여 주지 않음. |
| 영상 조작 | 재생·다시 보기·세 장면 이동·닫기. 큰 HTML 자막. 움직임 줄이기·자동재생 거절 시 직접 재생. 실패 시 마지막 그림과 설명 세 문장으로 대체. |
| 화면 | 질문의 중복 구역 배지 제거, 본문·버튼 확대, 오른쪽 패널 내용에 맞춰 중앙 정렬, 안내·대체 조작을 하나의 서랍으로 묶음. 보상 안내 반복 제거. |
| 팝업 | 일반 팝업의 제목과 스크롤 영역 분리. 중앙 정렬·일관된 닫기. 소개의 긴 목록 제거. 개념 영상과 방울이 설명을 나란히 배치하여 설명·버튼이 가려지지 않도록 구성. |
| 연구노트 | 도장마다 반복하던 대기 문장 제거. 획득 능력은 필요할 때 펼쳐 보기. 연구 기록을 두 열로 배치. |
| 캐릭터 | 현재 진행에 맞는 행동 안내, 두 단계 힌트, 다음 조작 강조. 힌트를 닫으면 실험으로 복귀. |
| 조작 | 현장 활동에서 물체 선택 → 놓을 곳 선택, 물길의 출발 → 도착 선택 지원. 기존 끌기와 함께 사용. 선택·목적지 강조, 관찰 돋보기의 실시간 확대 피드백. |
| 소리 | Kenney Interface Sounds의 CC0 효과음 7종. 클릭·도구 배치·관찰·힌트·연결·발견·완료에 적용. 배경 음악·효과음 독립 설정, 한 번에 효과음 한 개, 영상 중 배경 음악 정지. |
| 배포 파일 | WebM·MP4·끝 장면 WebP 및 효과음·라이선스 포함. 개발 서버의 미디어 MIME·HTTP Range 지원으로 장면 이동 가능. |

학습지와 다른 핵심 활동인 직접 붓기, 예상선 조절, 조건을 바꿔 비교, 그림의 시간 변화, 부분 닦기와 재응결, 공간 배치와 중력 물길 연결을 유지했다. 새로운 탭 조작은 끌기가 어려운 학생의 대체 수단이며, 관찰·비교 조건을 생략하거나 클릭 횟수만으로 통과시키지 않는다.

## 검증

- `npm run check`: 전체 소스 문법 통과.
- `npm test`: **52개 통과**. 기존 저장·교사 시연 분리·활동 완료·설계·소리·설정 포함.
- `npm run build`: 정적 사이트 빌드 통과. 빌드 결과에서 영상 자동재생·닫기, HTTP Range, 소개 창 3개 크기, 인증서 인쇄 표시 확인.
- 화면: 1280×800, 1024×768, 1920×1080, 1440×900, 1280×720. 지도와 10개 실험·10개 현장 의뢰 **105개 조합**, 설정창 **5개** 점검. 화면 밖 넘침·가로 스크롤·실행 오류 0. 가장 낮은 가로 화면의 6·9·10단계 내부 스크롤은 추가 수정 후 재측정했다.
- 완료 흐름: 현장 의뢰 10개, 실제 그림과 새로고침 복구, 실험→현장→영상→보상→다음 단계, 교사 시연·저장 분리, 소리 설정 보존, 두 종류의 최종 장치 고장 수리→10단계 영상→엔딩·새로고침. **16개 흐름 통과**.
- 영상: 10편 × MP4·WebM **20개 파일**의 9초 길이·960×540 크기·실제 재생 확인. 장면 자막 이동·재생 종료 그림·닫기·움직임 줄이기 확인.
- 효과음: **7개** 로컬 Ogg 파일 모두 디코딩 확인. 출처·CC0 원문 동봉.
- 팝업: 연구노트·설정·개념 영상 × 5개 크기 **15개 조합**에서 중앙 정렬·경계·44px 이상 버튼 확인.
- 추가 실제 조작: 두 그릇에 연속 붓기, 부분 닦기 후 같은 자리 재응결, 두 번 탭으로 옮기기·물길 연결, 잘못된 연결 거절, 캐릭터 힌트 2단계, 영상 실패 대체, 자동재생 거절 시 복구 통과.

로그·캡처: `docs/reviews/screenshots/experience-20261022/` 아래 `expedition-layout-results.json`, `expedition-flow-results.json`, `experience-results.json` 및 PNG. 의도적인 영상 닫기에서 발생하는 `ERR_ABORTED` 2건은 디코더·다운로드 해제에 따른 취소로 구분했다. 예기치 않은 네트워크 실패는 없다.

이전 UI 경로를 전제로 한 `scripts/tablet-interactions.py`는 소개 창과 현장 의뢰 게이트를 반영하지 않아 단독 실행이 맞지 않는다. 해당 실험 조작은 현재 경로를 사용하는 `scripts/experience-qa.py`, 완료·엔딩은 갱신한 `scripts/expedition-qa.py`로 검증했다.

## 주요 파일

- `src/concepts.js`, `src/concept-data.js`: 영상·자막·진행 연결.
- `src/coach.js`, `src/experience.css`: 단계 안내·힌트·화면 균형.
- `src/app.js`, `src/ui.js`, `src/fieldwork.js`, `src/phaser-scenes.js`: 기존 화면과 조작 통합.
- `src/sound.js`, `src/settings-content.js`, `public/assets/audio/`: 로컬 효과음과 고지.
- `scripts/concept-clips/`, `public/assets/concepts/`: 원본 모션 그래픽과 렌더 결과.
- `scripts/build.mjs`, `scripts/serve.mjs`: 빌드 포함·미디어 전송.

영상·포스터 전체 약 **1.88MiB**, 사용 효과음 약 **56KiB**다. 런타임 외부 음원 사이트·영상 서비스 요청은 없다. 영상 제작 방식과 장면은 `docs/design/CONCEPT-CLIPS-2026-10-22.md`, 음원 출처는 `public/assets/CREDITS.md`에 기록했다.
