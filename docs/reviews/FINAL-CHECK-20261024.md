> 로컬 온라인 실행본을 검증했다. 외부 배포는 하지 않았다. 실제 학생 수업·실물 태블릿·학교망·오프라인 배포는 별도 확인 대상이다.

## 이번에 적용한 변경

- **지도**: 물모양 샘터·얼음 다리·햇살 마당·이슬 정원·물길 공방을 나타내는 배경을 새로 생성하고 이동 지점을 맞췄다.
- **실험 도구**: 저울, 내부가 투명한 탱크, 응결 금속판을 생성 이미지로 바꿨다. 저울 숫자·물높이·기포·물방울은 실험 상태에 따라 그린다. 다른 도구에는 기존 장비 그림을 재사용했다.
- **시간 조작**: 1·5·6·7·8장에 52px 터치 영역의 시간 슬라이더를 넣었다. 앞으로 밀면 즉시 변화하고, 뒤로 밀면 지난 모습을 본다. 관찰한 최종 시점과 기록은 되돌리지 않는다. 지난 모습을 보는 중에는 기록을 덮어쓸 수 없다.
- **조작과 안내**: 주전자를 그릇에 놓으면 즉시 물을 붓는다. 그림·가열·응결·병 실험의 준비 조건을 드래그·앞으로·자동 재생·기록에 공통 적용했다. 현장 8의 비교 조건과 냉각팩 회수, 병을 닦은 뒤 안내를 보완했다.
- **완료 흐름**: 10장 기록 버튼을 가리던 개념 다시 보기를 방울이 힌트 안으로 옮겼다. 경사판과 밸브의 잡기 영역을 넓히고 경사 손잡이를 깔때기와 분리했다.
- **대체 화면**: Phaser가 열리지 않아도 8장의 두 병·시간 조절·응결 관찰·기록이 작동한다.
- **공통 화면·설정·저장**: 상단 이동/소리/설정 도구, 클릭해서 여는 힌트, 글자와 터치 크기, 설정 순서를 정리했다. 손상·다른 버전·다른 탭의 저장 원본을 자동 덮어쓰지 않으며, 교사용 시연은 학생 기록과 분리한다.

주요 파일: `src/inquiry.js`, `src/phaser-scenes.js`, `src/fieldwork.js`, `src/activities.js`, `src/journey.js`, `src/scene-model.js`, `src/coach.js`, `src/experience.css`, `src/app.js`, `src/settings.js`, `src/state.js`, `src/ui.js`, `scripts/build.mjs`.

이미지 원본·실행 파일·최종 프롬프트는 [이미지 생성 기록](ASSET-GENERATION-20261024.md)에 기록했다. 실행용 새 WebP 4개의 합계는 999,412B다. 생성 도구는 기본 내장 image_gen이며, 편집용 PNG는 `image/generated-learning/`에 보존했다.

## 남은 범위

1. 실제 태블릿·전자칠판·학교 AP에서의 수업 검증은 별도다.
2. 오프라인 새로고침과 처음 받지 못한 자산까지 보장하는 배포 방식은 아직 없다.
3. 원본 제공 이미지의 외부 배포 권리와 생성 서비스 요금제 범위는 기록만으로 확정하지 않는다.
4. 2·3장의 반복 목표를 추가하는 게임 구조 변경은 이번 기능·조작 개선에 포함하지 않았다.

전체 게임에 무관한 새 기능·패키지·로그인·분석 수집은 추가하지 않았다. 소스와 빌드의 동일성, 마지막 재빌드·구문 검사, AST 지식 그래프 갱신을 함께 확인한다.
