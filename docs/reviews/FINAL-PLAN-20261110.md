# 11월 10일 전체 점검과 수정 계획

## 요청 범위

차가운 병 실험 복원, 장면별 시계 배치, 관찰 화면 확대, 코어 연결과 조작 흐름, 코어를 깨운 뒤 3D 관찰, 엔딩 통계 상자 제거를 포함한다. 전체 학습·게임·저장 로직과 디자인을 점검한 뒤 커밋하고 기존 Cloudflare Pages 서비스에 배포한다. 실험에 쓸 CC0 물소리를 추가한다.

## 순서와 완료 기준

1. 기존 변경을 보존하며 활동 상태와 저장 복원 경로를 검토한다. 과거 저장의 병 관찰 단계도 정상 진입해야 한다.
2. 코어 고장 원인 선택, 수리, 시험, 연결, 입구 낮추기, 밸브 열기, 물 보내기, 깨우기, 3D 관찰, 온실 활동, 엔딩 순서가 끊기지 않게 수정한다.
3. 시계와 그림의 영역을 분리하고 관찰을 크게 배치한다. 1920×1080, 1280×800, 1024×768, 1024×600, 915×412와 세로 화면에서 조작 요소를 검사한다.
4. 물 따르기·물방울·기포 소리의 원저작자와 CC0 표기를 확인한다. 로컬 파일로 제공하고 음소거, 탭 전환, 중복 재생을 점검한다.
5. 단위 테스트, 구문 검사, production build, 브라우저 활동 경로·터치·저장·오프라인·네트워크 검사를 수행한다. 실패를 먼저 고친다.
6. edu-final-check A~G와 게임 조작 흐름 기준으로 근거와 미검증 항목을 남긴다. 10개 영역을 각각 10점으로 평가하고 전체 평균을 제시한다.
7. 수정 파일과 라이선스를 커밋하고 원격에 반영한다. 커밋 소스로 다시 빌드해 배포하고 실제 서비스에서 스모크 검사를 진행한다.

## 점검에서 먼저 확인한 문제

- 병 실험으로 넘어가는 조건이 새 요약 완료 상태와 맞지 않았다.
- 시계가 관찰 그림과 설명 위에 겹쳤다.
- 고친 뒤 고장 원인을 바꾸면 성공한 시험 결과가 재평가되지 않아 코어 연결이 막혔다.
- 비활성 버튼을 숨기는 공통 스타일 때문에 연결 단계 자체를 찾기 어려웠다.
- 코어 깨우기가 3D 관찰을 거치지 않고 다음 활동으로 이동했다.
- 코어 높이와 밸브 슬라이더가 큰 관찰 영역을 차지하고 조작 순서를 분명히 보여 주지 못했다.

## 검증 범위의 경계

브라우저 에뮬레이션은 실제 학교 태블릿, 교실 와이파이, 학생 사용성 관찰을 대체하지 않는다. 해당 항목은 별도 미검증으로 표시한다. 효과음은 CC0로 명시된 소스를 사용하며 기존 이미지·음악의 출처 기록도 함께 확인한다. 모든 직접 생성 파일·캐시·빌드·검사 자료는 연결된 외장 T7 Shield에 저장한다.
