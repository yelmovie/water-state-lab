# 물방울 연구실 2.0 개편·검증

2026-10-15. 요청한 활동·이미지·캐릭터·보상 개편을 구현했다. `final-check`의 교육 동기·선택–결과–수정·실제 기록 전이, 화면 가독성, 저장 복원 기준을 참고했다. 이 문서는 확인한 구현과 로컬 동작의 기록이며 학생 대상 학습효과·재미 평가나 공개 배포 승인서가 아니다.

## 달라진 경험

- 첫 화면 자체가 생성 이미지 연구섬이다. 다섯 지점은 그림의 실제 발판에 맞췄고, 방울이는 연결된 길의 좌표를 따라 이동한다. 이미 얻은 연구 기록에 따라 길과 도구가 표시된다.
- 기존 제공 방울이의 16개 포즈를 사용한다. 모든 활동에 목표, 세 단계 진행 표시, 현재 상태에 따른 다음 행동, 도움말이 있다.
- 새로 생성한 지도 1장, 실험 도구 9종, 공방 부품·코어 6종을 적용했다. 설명용 상태 변화는 동적인 SVG/Canvas로 유지한다.
- 속도나 반복 클릭 점수 대신 관찰·조건 비교·증거 설명·수정한 설계를 보상한다. 보상은 다음 구역의 접근과 연구노트, 실제 기록을 읽는 다음 활동으로 이어진다.
- 이전 홈·이전 페이지·소리·설정·관리자 전체 해금 기능을 유지했다. 관리자 미리보기의 예시 데이터는 학생 완료 기록에 들어가지 않는다.

## 활동별 의미와 데이터 연결

| 화면 | 해결할 일과 실제 조작 | 선택이 바꾸는 것 / 다음에 쓰는 것 |
|---|---|---|
| 1 | 주전자를 두 그릇으로 옮기기, 얼음 이동, 천 문지르기와 시간 관찰 | 액체·고체의 모습 차이와 마른 물자국 기록 → 상태 분류 |
| 2 | 실험 그림 3개와 생활 사례 3개를 세 상태 보관함에 끌어 분류 | 잘못 연결하면 관찰 근거 안내. 상태 기록·돋보기·다음 구역 획득 |
| 3 | 저울에 물통 놓기, 예상선 남기기, 냉각·가열 도구로 얼리고 녹여 재측정 | 예상과 세 시점의 높이·무게 보존 → 배관의 여유 공간 판단 |
| 4 | 물 채움 정도를 바꾸고 두 조건 시험, 남는 공간 표시, 사용할 조건 선택 | 채움에 따른 팽창·공간 부족 결과. 15 이상 다른 조건 비교 필요 |
| 5 | 직접 물그림을 그리고 물의 양이 다른 같은 그림을 세 시점에서 기록 | 시간에 따른 자국 변화와 더 빨리 마르는 조건. 그림을 고치면 이전 기록 무효화 |
| 6 | 무가열 대조 조건 기록 후 가열 비교, 돋보기를 표면·물속·수위로 이동 | 가열 0이면 두 용기 감소량 동일. 실제 비교 기록과 수증기의 행방 연결 |
| 7 | 차가운/실온 용기 닦기·밀봉·동시간 비교, 다시 닦고 재응결 확인 | 두 용기의 물방울·전체 무게 기록과 재관찰 증거 → 8번에서 그대로 사용 |
| 8 | 자신의 증거 두 장과 출처–조건–결과 연결, 차가운 음료병 닦고 재관찰 | 새 상황에도 같은 응결 원리 적용. 응결 보고서·공방 냉각판 획득 |
| 9 | 냉각판·경사판·깔때기·관·물통을 조립하고 시험 뒤 수정 | 첫 끊긴 지점, 수집·손실 지수 변화. 서로 다른 설계 시험과 현재 성공 설계 필요 |
| 10 | 저장 장치·실제 기록을 읽고 냉각을 복구, 출구 연결·밸브·레버 조작 | 저장된 장치의 성공 여부와 응결 조건을 사용해 코어 가동, 개인 기록이 있는 엔딩 |

교육과정은 2022 개정 [4과10-01]~[4과10-03]과 대조했다. 세 상태·생활 사례, 얼기·녹기·증발·끓음·응결 관찰, 물 수집 장치 설계를 연결한다. **가상 설계만으로 실제 장치 제작까지 수행했다고 표시하지 않는다.** 실제 만들기는 별도 수업 활동으로 연결한다. 물높이·시간·물방울 수·수집 지수는 비교를 위한 가상 값이다. 수증기를 눈에 보이는 흰 김과 동일시하지 않는다.

## 확인하지 않은 것

- 실제 학생의 이해도, 활동 소요 시간, 재미와 난이도: 사용자 수업에서 확인 필요. 구현만으로 ‘참고 프로젝트보다 좋다’거나 학습효과를 보장하지 않는다.
- 학교 태블릿의 터치 하드웨어, 저사양 성능, 학교 와이파이 로딩 시간: 해당 기기·네트워크가 없어 미측정. 로컬 서버 로딩을 학교 환경 결과로 환산하지 않았다.
- 완전 오프라인 실행과 연결 단절: 서비스워커를 추가하지 않았으며 보장하지 않는다.
- 공개 배포 URL: 이번 요청에서 배포하지 않았으므로 배포 후 접속 검증은 미실시.
- 제공 원본의 공개·상업 배포 권리와 제작자 최종 표기: 소유자가 배포 전에 확인할 사항. 에셋 출처와 생성 프롬프트는 별도 기록에 보존했다.
