# 물방울 연구실 활동과 시각 고도화 계획

사용자 요청에 따라 10개 화면을 유지하면서 활동·연결 서사·보상·이미지 구성을 개편한다. 기존 소스는 `tmp/baseline-v1-src`에 보관한다. 외부 비교 프로젝트는 읽기만 한다.

## 학습 기준

- [4과10-01] 물의 세 상태와 주변 사례
- [4과10-02] 얼기·녹기·증발·끓음·응결 관찰
- [4과10-03] 상태 변화를 이용한 물 얻는 장치 설계와 제작
- 공식 대조: 충북교육청 「2025 충청북도 초등학교 교육과정」 2022 개정 각론 p.93. https://pain.cbe.go.kr/upload/dept-19/na/bbs_1437/2025/01/42D2EF47-B7BF-7348-32ED-418D79977B1A.pdf#page=93

## 경험 설계

| 화면 | 문제와 수행 | 비교 또는 수정 | 실제 보상과 후속 연결 |
| --- | --- | --- | --- |
| 1 | 물 붓기, 얼음 옮기기, 젖은 자국 만들기 | 전후 모양과 자국 관찰 | 관찰 사진을 2번 분류에 사용 |
| 2 | 관찰과 생활 그림을 상태 보관함으로 옮기기 | 잘못 연결한 근거 다시 살피기 | 관찰 렌즈와 첫 길 복구 |
| 3 | 같은 물을 올리고 예상선·냉각 도구 조작 | 처음, 얼음, 다시 물 비교 | 측정 기록을 4번 공간 판단에 사용 |
| 4 | 물 양을 바꾸어 배관 시험 | 두 조건과 여유 공간 비교 | 안전 밸브와 다리 복구, 최종 설정에 기록 사용 |
| 5 | 물로 직접 그림 그리고 관찰 시간 조절 | 같은 그림의 물 양만 다르게 비교 | 시간 기록을 6번 비교에 사용 |
| 6 | 가열 손잡이, 표면과 내부 돋보기 조작 | 무가열과 가열, 수위와 기포 비교 | 시간 관찰기와 수로 복구 |
| 7 | 차가운 컵과 실온 컵 닦기, 밀봉, 재관찰 | 대조군과 재닦기 후 물방울 생성 비교 | 실제 관찰 장면을 8번 증거로 사용 |
| 8 | 원인과 조건과 결과에 증거 놓기 | 새로운 음료병 사례에 적용 | 냉각판과 응결 정원 복구, 공방 핵심 부품 |
| 9 | 부품 끌기, 기울기 조절, 물길 시험 | 손실 지점을 찾아 수정하고 재시험 | 실제 확정 설계와 개선 기록을 10번에 사용 |
| 10 | 자신의 장치 연결, 기록을 활용한 새 문제 해결 | 냉각 또는 공간 설정을 복구해 물길 확인 | 연구섬 전체 복구와 실제 연구 앨범 |

속도·반복 클릭에 보상하지 않는다. 비교·근거·개선 행동은 최초 달성 시 배지로 남기고, 미션 완료는 지도 복구·도구 획득·다음 길 개방으로 나타낸다. 방울이는 각 화면의 요청, 다음 행동, 실패 이유, 발견에 반응한다.

## 시각 구현

새 길지도와 실험 도구 아틀라스를 내장 이미지 생성으로 제작한다. 기존 방울이 표정 시트와 고품질 배경을 실제 화면에 적용한다. HTML/CSS는 레이아웃·접근성·동작에 사용하고, 정적인 캐릭터·도구·환경은 이미지 자산으로 표현한다. 측정 눈금과 물의 동적 수위는 읽기 쉬운 SVG/Canvas로 남긴다. 실제 실시간 3D 렌더러 교체는 이번 범위에 포함하지 않는다.

## 검증

저장 호환·해금·재진입·음소거·키보드 대체 조작, 새 시뮬레이션의 공정 비교, 완료 조건과 보상 중복 방지를 테스트한다. 1280×800, 1920×1080, 1024×768, 915×412에서 시각·흐름을 확인하고 final-check 기준의 미션 가치표를 작성한다. 실물 제작과 학생 대상 학습효과 검증은 가상 실험 실행과 구분한다.
