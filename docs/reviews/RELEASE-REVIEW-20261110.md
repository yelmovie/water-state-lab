## 실행한 검사

- 단위 테스트 267개 통과, 구문 검사 통과.
- 전체 실험 1~10과 현장 활동 2·4·10, 그림 저장 복원, 코어→3D→온실→개념 정리→엔딩, 엔딩 새로고침을 브라우저로 검사했다. 단계별 초기 상태를 구성한 후 실제 버튼과 캔버스 조작을 사용했다. 새 사용자 한 명의 무중단 전체 수업 시간 실측과는 범위가 다르다.
- 1920×1080, 1280×800, 1024×768, 1024×600, 915×412, 390×844에서 78개 화면을 검사했다. 통합 뒤 발견한 세로 화면 교사용 버튼 겹침 두 곳을 고쳤다. 수정한 커밋의 독립 배포 빌드에서 전체 78개 화면을 다시 검사해 문제 0건을 확인했다.
- 1024×600 터치 에뮬레이션으로 얼기·녹기 측정과 온실 순환을 완료했다. 모달을 열었을 때 관찰 시간이 멈추고 새로고침 후 복원되는 경로도 확인했다.
- 브라우저에서 코어 연결 전 비활성 이유, 수정된 원인 선택, 연결, 높이 조작, 물 보내기, 3D 로딩·회전·닫기·재진입을 확인했다.
- 대표 선택지와 주 조작 문구는 1920 폭에서 21~26px, 1024 폭에서 16~20px였다. 이 수치는 모든 보조 캡션의 하한 측정을 의미하지 않는다.
- 로컬 production build의 캐시 없는 첫 화면은 준비 632ms, DOMContentLoaded 604ms, 전송 3,532,974바이트, 리소스 81건이었다. 외부 호스트 요청과 페이지 오류는 0건이었다. 학교 와이파이 속도 측정값은 아니다.
- 실제 서비스워커의 warm 메시지를 반복해 캐시를 완료한 뒤 네트워크를 끊었다. 진행 중 화면 새로고침과 아직 방문하지 않았던 연구섬 3D 로딩이 통과했다.
- 새 MP3 세 개를 브라우저 AudioContext로 디코딩했다. 길이, 비무음 신호, 최대 진폭이 정상 범위였다. 사람의 귀로 듣는 음질 검수는 수행하지 않았다.
- graphify 구조 그래프를 갱신했다. Impeccable 탐지기의 기존 카드 측면 테두리 경고는 게임 조작·학습을 막는 오류로 분류하지 않았다.

검사 자료는 외장 SSD의 `.tmp/merged-*`, `.tmp/text-metrics/`, `.tmp/core-connect-3d-qa/`, `.tmp/clock-layout-qa/`에 있다. 캐시·임시파일·빌드도 같은 외장 SSD에 생성했다. 원격 변경을 통합하는 과정에서 나온 구버전 테스트 선택자와 병합 오류는 수정 후 재실행했다.
