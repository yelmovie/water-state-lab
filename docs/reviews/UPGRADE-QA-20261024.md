# 전체 페이지 고도화 QA · 2026-10-24

이번 문서는 화면 렌더·미디어·자산·로컬 네트워크 검증을 기록한다. 학습효과·스테이지 게임성 판정과 저장 핵심 경로 검증은 최종 통합 보고서에서 별도로 다룬다. 외부 배포는 하지 않았다.

## 검사 환경과 재현

- 설치된 Google Chrome headless, 새 임시 프로필. 사용자의 브라우저·학습 기록에 연결하지 않았다.
- 대상: `http://127.0.0.1:4318`, 로컬 개발 서버. 교실 AP·실물 태블릿 속도를 모사한 결과가 아니다.
- 증거: `docs/reviews/screenshots/upgrade-20261024/`. 이전 보고서·스크린샷을 덮어쓰지 않고 `baseline`과 `final`을 분리했다.
- `scripts/upgrade-qa.py`는 `assets`, `experience`, `network`, `supplemental` 모드를 지원한다. 기존 `expedition-qa.py`, `experience-qa.py`, `expedition-network.py`를 재사용하며 현재 설정창의 연구노트 진입점을 반영한다.
- 1280×800, 1024×768, 1280×720을 우선하고 906×755, 873×580, 375×812, 768×1024, 1440×900, 1920×1080을 함께 확인한다.

## 자산·출처

`public/assets`의 파일별 경로·용량·형식·수정 시각·SHA-256·정적 참조는 `final/asset-results.json`에 기록한다. 정적 참조가 없다는 이유만으로 미사용을 확정하지 않았다.

| 분류 | 개수 | 용량 | 확인 |
|---|---:|---:|---|
| 이미지 | 34 | 26,864,891 B | 편집용 PNG 원본 포함. 실행 WebP 중 최대 779,766 B |
| 영상 | 20 | 1,898,666 B | 개념 영상 10편의 MP4·WebM |
| 효과음 | 7 | 57,721 B | 로컬 Ogg, Kenney 출처·CC0 전문 동봉 |
| 폰트 | 2 | 384,792 B | 로컬 Jua, OFL 전문 동봉 |
| 기타 | 6 | 실행 시 재측정 | Phaser·라이선스·출처 문서 |

- ffprobe로 MP4 10개는 H.264/yuv420p, WebM 10개는 VP9/yuv420p임을 확인했다. 전부 960×540이다. WebM은 Chrome이 VP9 재생 가능 여부를 확인한 뒤 선택하며 MP4 대체 경로를 보존한다.
- 완전히 같은 SHA-256 중복 0개, 소스의 `/assets/` 리터럴 경로 누락 0개다. 동적 영상 경로는 별도 재생 검증 대상으로 다룬다.
- 1MB를 넘는 이미지는 초기 MVP·편집용 PNG 원본이다. 빌드 스크립트는 실행용 WebP를 복사하고 이 PNG들은 제외한다. 파일 삭제·이동은 하지 않았다.
- 현재 효과음은 내려받은 Kenney 파일인데 이전 CREDITS 상단은 모든 효과음을 합성한다고 적고 있었다. 상단을 현재 구현에 맞게 수정했다.
- 사용자 제공 초기 이미지의 외부 배포 권리를 새로 확인하거나 추정하지 않았다. 이전 출처 기록과 확인 필요 사항을 유지했다.
- 기능 이모지 검색 결과 0건. 벡터 아이콘 유지 근거는 `docs/icon-prompts.md`, 보존·미사용 후보 근거는 `_unused/DELETE-CANDIDATES.md`에 갱신했다.

## 최종 통합 재검증

최종 빌드는 `http://127.0.0.1:4325`에서 검증했다. 기준 결과는 `screenshots/upgrade-20261024/release/`다.

- `expedition-all-results.json`: 63개 화면·설정창3개 레이아웃 통과. 당시 저장 검사 준비 오류2건은 보존했다.
- `expedition-flow-results.json`: 유효한 학생 선행 기록으로 준비를 바로잡고 현장10종·복원·시연격리·초기화·두 최종 수리를 포함한16흐름 통과.
- `time-drag/results-final.json`: 10장 버튼 가림 수정 후 실제 클릭, 확대 손잡이, 개념 다시 보기, 두 엔딩 재검증 통과.
- `release/final-smoke-results.json`: 최신 지도·Phaser 미수신 시 병 관찰/시간드래그/기록 통과.
- 소스·빌드 구문 검사와71개 단위검사 통과. 마지막 관련37개 재검사도 통과했다.
- 현재 새 이미지4종은 별도 `ASSET-GENERATION-20261024.md`에 기록했다. 위 자산 개수는 이미지 추가 전 1차검사 값이다.

이번 판정·남은 범위·장별 매트릭스는 `FINAL-CHECK-20261024.md`를 따른다. baseline과 최초 실패를 최종 통과로 덮어쓰지 않았다.
