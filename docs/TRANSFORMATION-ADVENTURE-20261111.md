# 변신 모험 1차 구현

현재 반영 상태는 문서 아래의 ‘후속 요청에 따른 현재 동작’과 ‘추가 사용성 수정’을 기준으로 한다. 2026년 11월 12일 커밋·배포·공개 화면 대조 결과는 `reviews/CHANGE-RECONCILIATION-20261112.md`에 기록했다.

## 보존과 연결
기존 10개 실험, 5개 연구기록, 교사 시연, 저장 형식의 기존 필드는 보존한다. 새 dropAdventure 상태를 선택적 필드로 저장하며 기존 기록에 기본값을 강제로 덮어쓰지 않는다.
홈에서 변신 모험 진입 → 각 지역 실험 두 개를 완료해야 변신 도구 해금 → 실험 완료 후 모험 복귀 → 열 출입과 상태 변화로 길 통과 → 다음 지역에서 다시 탐구하는 순서다. 기존 완료자는 다시 실험하지 않아도 된다. 모험 없이 기존 실험을 계속할 수 있다.

## 5개 지역 / 11개 관문
1. 녹여 좁은 수로 통과, 다시 얼려 운반대 이동.
2. 얼 때 늘어날 공간 확보, 녹여 출구 수로 이동.
3. 증발하여 공기길 이동, 차가운 판에서 응결.
4. 응결하여 물 수집, 얼려 보관.
5. 녹기·증발·응결을 종합하여 온실 물길 연결.
각 단계는 틀렸을 때 상태를 유지하며 개념에 맞는 행동 힌트를 준다. 목숨/시간 압박 없음. 버튼과 관문 클릭 및 키보드 기본 버튼 접근 제공.

## 과학과 게임 구분
열 출입·얼기/녹기/증발/응결, 얼 때 부피 증가를 사용한다. 두 번 버튼을 누르는 시간·이동 길·운반대는 게임 규칙이다. 수증기는 보이지 않으므로 캐릭터는 위치표시임을 명시한다. 실제 뜨거운 물 조작을 요청하지 않는다. 게임의 통과는 이해도의 확정 판정이 아니다.

## 현재 범위
연결된 변신 모험 흐름을 새로 구현했으며 기존 10개 실험 자체를 모두 어드벤처로 전면 교체하지 않았다. 지역별 배경과 복잡한 물리 플랫폼 조작은 기존 에셋을 활용한 동일한 관문 형식이다. 실제 아이의 재미/학습효과 검증은 아직 없다.

## 검증
285개 단위 테스트·문법 검사 통과. 1280×800, 1024×768, 873×580, 390×844에서 5개 지역을 실제 버튼 입력으로 완료. 이 검사는 실험 완료 기록을 주입해 모험만 완주했으며 10실험 신규 자연 완주와 같지 않다. 저장 복귀, 잠금 상태에서 실험 이동, 오답/재시도는 별도 확인. 실물 태블릿 미시험.

## 11월 11일 이어받아 마무리한 내용

- 이전 Claude 중단분의 통합 기록과 최신 변신 모험 커밋을 대조한 뒤 현재 변신 모험의 연결과 복원을 보완했다.
- 각 지역의 첫 실험을 이미 마쳤다면 두 번째 실험부터 이어진다. 마지막 지역도 9장 장치를 다시 제출해 10장 수리 진행을 초기화하지 않고 10장으로 돌아간다.
- 홈이나 지도로 나가면 실험 후 모험 복귀 예약을 해제한다. 모험을 다시 시작할 때도 지난 복귀 예약을 정리한다.
- 모험 상태의 기본값을 기존 저장 모델에 추가해 교사 시연 종료 시 학생의 모험 기록과 복귀 예약이 복원되도록 했다. 기존 저장에 들어 있는 모험 기록은 보존한다.
- 915×412 가로 화면에서는 장면과 조작 영역을 나란히 배치한다. 작은 보조 글씨를 16px로 올리고 수증기 위치 설명이 장면 안내와 겹치던 배치를 수정했다.
- 모험의 이전 페이지 경로와 관문 이동 접근성 문구를 정리했다.

### 이번 검증 결과

- 회귀 테스트 3개가 수정 전 실패하는 것을 확인한 뒤 수정했다. 전체 단위 테스트 288개, 문법 검사, 빌드, diff 공백 검사가 통과했다.
- 기존 브라우저 검사로 1~10장 조작, 2·4·10장 현장 의뢰, 코어 수리, 3D 관찰 이후 온실·엔딩과 저장 복원을 확인했다. 장면 21개에서 배치 문제와 브라우저 오류가 없었다. 각 장의 시작 조건을 설정하는 회귀 검사다.
- 1920×1080, 1280×800, 1024×768, 1024×600, 915×412, 390×844에서 모험 5지역의 11관문을 터치 입력으로 통과했다. 오답·잠금·다음 지역·새로고침 복원을 검사했다. 모험 완주 검사는 실험 완료 기록을 넣어 모험을 독립적으로 검사했다.
- 915×412와 390×844 캡처를 직접 열어 조작 버튼과 수증기 안내의 가독성·겹침을 확인했다.
- 배포용 빌드의 새 기록에서 1·2장 실험과 현장 의뢰를 실제 클릭·드래그로 완료하고 모험으로 복귀했다. 첫 지역의 두 관문을 통과한 뒤 다음 지역의 3장 실험에 진입했다. 이 연결 검사에는 실험 완료 기록을 주입하지 않았으며 브라우저 오류는 없었다.
- 배포용 빌드에서 서비스워커 활성화 후 인터넷을 끊고 새로고침한 다음 상태 변화·이동·저장을 확인했다.
- 검사 자료는 외장 SSD의 `.tmp/adventure-resume-20261111/`, `.tmp/resume-chapters-20261111/`, `.tmp/adventure-natural-built-20261111/`에 둔다. 코드 그래프도 갱신했다.
- 실제 태블릿, 실제 스피커 청취, 새 기록 하나로 10개 실험을 연속 완주하는 검사는 이번에 수행하지 않았다. 이번 수정의 원격 반영과 운영 배포는 미실행이다.

## 장치 이미지와 상태 변화 연출 · 11월 11일 추가 요청

- 같은 방울이 그림의 색만 바꾸던 표시를 새 물방울·얼음 이미지로 교체했다. 수증기는 눈에 보이지 않으므로 얼굴이나 구름 대신 점선 위치 표시를 사용한다.
- 냉각 관찰대·수로·증발 그릇·응결 수집판을 개별 생성해 11개 관문에 연결했다. 장치의 용도를 이미지와 짧은 설명으로 함께 보여 준다.
- 냉각 장치의 물높이·여유 공간·얼음 표면, 수로의 흐르는 물, 차가운 판의 물방울을 코드로 겹쳐 표현한다. 녹기·얼기·증발·응결은 교체 애니메이션을 사용하며 이동 버튼은 다음 장치까지 이동하는 애니메이션을 재생한다.
- 화면이 좁으면 장치를 옆으로 밀어 살펴볼 수 있고 현재 장치가 보이도록 맞춘다. 움직임 줄이기 설정에서는 즉시 상태를 표시한다.
- 기존 실험 해금·오답 판정·5지역 진행·저장 형식을 사용한다. 실행 에셋 6개는 `public/assets/learning/adventure-20261111/`, 내장 image_gen에 전달한 프롬프트와 PNG 원본은 `assets/source-media/adventure-20261111/`에 있다.
- 별도 요청한 연한 금색 버튼의 흰 글씨도 공통 스타일에서 진한 갈색으로 수정했다. 일반·마우스 올림·키보드 포커스·누름·투명도 줄이기 상태를 검사했다.

이번 추가 검증은 단위 테스트 290개·구문 검사·빌드를 통과했다. 6개 화면 크기에서 5지역 완주·오답·잠금·복원을 검사했고, 별도 애니메이션 검사에서 여유 공간 없을 때 얼기 중단, 얼음 이미지 교체, 실제 장치 간 이동, 녹기, 재접속과 움직임 줄이기를 확인했다. 레이아웃 24개 상태를 캡처했고 브라우저 오류와 이미지 누락이 없었다. 모험 완주 검사는 실험 완료 기록을 설정한 독립 검사이며 실물 기기 검사는 아니다. 새 원본의 외장 SSD 사본을 바이트 비교한 뒤 이번 생성으로 생긴 내장 임시 원본 6개만 정리했다.

## 11월 11일 후속 요청에 따른 현재 동작

- 변신 모험 5개는 실험 기록 없이 진행하는 독립 모드다. 위에 기록된 실험 해금 조건과 실험 후 모험 복귀 연결은 해제했다.
- 수조 출구와 수로 그림을 오른쪽 흐름으로 다시 만들고, 수면·물방울·앞쪽 돌벽을 분리해 높이와 가림 순서를 맞췄다. 수증기 표시는 상태를 설명하는 문구로 바꿨다.
- 컵 비교는 ‘컵 닦기’ 버튼 한 개로 두 컵을 닦고 재관찰한다. 중복 질문 때문에 생기던 상하 겹침을 제거하고 다음 버튼을 ‘관찰결과 확인하기’로 바꿨다.
- 시계는 투명 배경 위에서 바늘이 움직이고 관찰 완료 시 사라진다. 공통 관찰 속도 계수를 0.5에서 0.75로 높였다.
- 본편 완료 후 남은 밸브 두더지를 모두 제거해야 엔딩 영상이 열린다. 퇴치 기록과 엔딩 대기 상태는 새로고침 후 이어진다. 교사 시연은 엔딩 미리보기를 제공한다.
- 엔딩의 자기평가 카드를 제거했다. 그림 카드와 오른쪽 제목·버튼 영역의 높이를 맞추고 ‘탐구 노트’ 명칭을 사용한다.
- 악당과 방울이의 실제 표시 영역이 닿으면 새 피격 포즈, 물방울 파편, 충격 링, 반동과 기존 효과음이 동작한다. 1.3초의 연속 피격 보호를 두고 움직임 줄이기 설정을 반영한다. 학습 기록에는 영향을 주지 않는다.

검증은 단위 테스트 299개, 구문 검사, 실제 방향키 접촉과 회복, 팝업·화면 전환 시 정리, 투명 시계와 약 11.2초 관찰, 5개 모험 독립 완주, 악당 정리 후 영상 재생과 새로고침 복구, 엔딩 6개 화면 크기를 포함한다. 실물 태블릿과 실제 스피커 출력은 별도로 검증하지 않았다.


## 추가 사용성 수정

- 물통 자동 채우기는 기존 SVG와 이미지를 유지하고 물높이만 갱신한다. 직접 채우기도 값이 바뀔 때만 갱신한다.
- 물그림 결과를 고른 뒤 이전 선택지는 접힌다. 가열 비교는 같은 양의 시작 상태를 기록하고 B만 가열하여 한 번 관찰한다.
- 컵은 한 번 닦고 한 번 관찰하면 완료된다. 다시 닦기와 새 음료병 관찰은 추가 탐구이며 진행 조건에서 제외했다. 실제로 하지 않은 추가 탐구를 증거에 기록하지 않는다.
- 자동 관찰은 기본으로 꺼져 있다. 교사용 설정에서 켜면 실험 화면에 상태가 표시된다. 첫 실험의 물 붓기, 얼음 옮기기, 다음 단계로 이동은 학생이 직접 한다.
- 지도 지역 선택은 입구로 이동만 한다. 가까이에서 Enter 또는 들어가기 버튼을 눌러 입장한다.
- 장치 관찰의 2D 회전 팝업 진입을 제거하고 3D 관찰을 유지했다.
- 연구노트 도장은 3개와 2개로 배열한다. 연구 기록은 초등 수준의 한국어 문장으로 요약하고 과학 개념을 강조한다.
- 연구 인증서는 가로형으로 재배치했다. 강점 배지와 별도 장식 도장은 제거하고 제목과 본문을 굵게 표시한다.
- 되살린 연구섬 다시보기는 휠·핀치와 버튼으로 최대 5배 확대한다. 오른쪽 끌기 또는 두 손가락 이동으로 관찰 중심을 옮기고 전체 보기로 복구한다.
- 브라우저에서 전체 실험 10개와 현장 과정, 지도 입장, 자동 채우기 DOM 유지, 설정 전환, 노트 배열, 인증서 인쇄, 3D 휠 확대를 확인했다. 태블릿 실기기에서의 핀치 조작은 미확인이다.

최종 검증은 단위 테스트 300개 통과, 전체 실험 흐름 21개 화면의 겹침 검사 통과, 인증서 A4 가로 1장 PDF 확인을 포함한다. 화면 크기 1280×800, 1024×768, 1024×600, 915×412, 390×844에서 인증서 내용 잘림이 없었다.
