# 교사용 안내 · 방울이의 물길 탐험 (06 물의 상태 변화)

## 1. 한 줄 소개

방울이와 연구섬의 다섯 구역을 다니며 물을 붓고 얼리고 말리고 맺히게 하는 실험 10개와 현장 의뢰 3개를 하고, 마지막에 물을 모으는 장치를 설계하는 물의 상태 변화 탐구 게임입니다.

## 2. 대상

| 항목 | 내용 |
|---|---|
| 학년·학기 | 초등 4학년 1학기(운영 시트 「이예리 선생님」 탭, 2026-11-22 확인) |
| 과목 | 과학 |
| 단원 | 「물의 상태 변화」(운영 시트 단원명). 교과서 단원 번호는 확인 필요. |
| 성취기준 | [4과10-01] 물이 세 가지 상태로 변할 수 있음을 알고, 우리 주변에서 예를 찾을 수 있다. |
| | [4과10-02] 물이 얼 때, 얼음이 녹을 때, 물이 증발할 때와 끓을 때, 수증기가 응결할 때의 변화를 관찰할 수 있다. |
| | [4과10-03] 물의 상태 변화를 이용하여 물을 얻을 수 있는 장치를 설계하고 만들 수 있다. |

성취기준 문장은 사용자가 제공한 연결을 코드에 적은 것이고, 교육과정 원문과 글자 단위로 대조하지 않았습니다. 장 연결은 1~2장이 4과10-01, 3~8장이 4과10-02, 9~10장이 4과10-03입니다.

## 3. 준비

- 기기: 태블릿(가로 화면)을 기본으로 하고, 전자칠판과 PC에서도 열립니다. 설치 없이 브라우저로 엽니다.
- 소리: 배경 음악, 효과음, 목소리가 있고 설정에서 각각 끌 수 있습니다. 설정의 「움직임 줄이기」로 움직임을 줄일 수 있습니다.
- 안전: 실제로 뜨거운 물이나 전기 기구를 쓸 때는 선생님이나 보호자와 함께합니다. 화면의 가열은 가상 실험입니다.
- 예상 시간: 문서에 정해진 수업 시간이 없습니다(확인 필요). 40분 수업은 아직 확인하지 않았습니다.

## 4. 차시 흐름

시작 화면 → 인트로 영상 → 탐험 지도 → 구역마다 앞 실험, 주민 대화, 뒤 실험, 현장 의뢰 또는 개념 정리 → 마지막 물길 복구 → 엔딩 영상 → 인증서 순서입니다. 지도에는 밸브 두더지가 나오고, 물리치면 성취 카드를 받습니다(카드 5장). 시작 화면의 「방울이 변신 모험」은 선택 활동입니다.

| 구역 | 활동 | 학생이 하는 일 | 배우는 개념 |
|---|---|---|---|
| 1 물모양 샘터 | 1장 그릇을 바꾸면 | 같은 물을 두 그릇에 나눠 붓고, 얼음도 옮겨 비교합니다 | 물은 그릇에 따라 모양이 바뀌고 얼음은 그대로입니다 |
| | 2장 어떤 물의 모습일까 | 생활 장면 카드 6장을 고체·액체·기체로 나눕니다 | 얼음·물·수증기는 물의 세 모습입니다 |
| | 현장 의뢰 2 네 갈래 변신길 | 얼리기·녹이기·증발·응결에 맞는 도구를 골라 결과를 확인합니다 | 물의 상태가 바뀌는 길 |
| 2 얼음 다리 | 3장 얼면 높이와 무게 | 예상하고, 얼리고, 녹여서 높이와 무게를 비교합니다 | 얼면 높이는 높아지고 무게는 같습니다 |
| | 4장 얼음이 커질 자리 | 시험관에 물을 가득 담았을 때와 덜 담았을 때를 비교합니다 | 물이 얼면 부피가 커집니다 |
| | 현장 의뢰 4 한파가 온다 | 통에 공간을 남긴 까닭을 고릅니다 | 얼음이 커질 공간이 필요합니다 |
| 3 햇살 마당 | 5장 내 물그림 | 물을 다르게 묻힌 두 그림이 마르는 순서를 예상하고 관찰합니다 | 물은 수증기가 되어 공기 중으로 갑니다 |
| | 6장 끓지 않아도 | 두 컵을 비교하고 한 컵만 데웁니다(실제 가열은 교사가 합니다) | 증발은 끓지 않아도 일어납니다 |
| 4 이슬 정원 | 7장 닦은 자리에 또 | 입구를 막은 차가운 컵의 물방울을 닦고 다시 비교합니다 | 컵 속 물이 샌 것이 아닙니다 |
| | 8장 관찰 결과 확인 | 증거를 모아 설명하고 다른 차가운 병에도 적용합니다 | 수증기가 차가운 표면에서 응결합니다 |
| 5 물길 공방 | 9장 어디를 고칠까 | 경사판과 깔때기를 맞추고 새는 곳을 고쳐 물을 모읍니다 | 응결과 물이 높은 곳에서 낮은 곳으로 흐름 |
| | 10장 물이 도착하지 않는 이유 | 장치가 멈춘 원인(냉각 또는 물길 연결)을 찾아 고칩니다 | 상태 변화를 이용한 물 모으기 |
| | 현장 의뢰 10 마지막 순환 회로 | 물 → 수증기 → 물방울의 길에 알맞은 도구를 연결합니다 | 증발과 응결의 이어짐 |

선택 활동 「방울이 변신 모험」은 열 조절 버튼으로 방울이의 모습(얼음·물·수증기)을 바꿔 길을 통과합니다.

## 5. 정답과 판정 기준

| 활동 | 정답 또는 통과 조건 |
|---|---|
| 1장 | 문항이 없습니다. 붓기, 얼음 옮기기, 물자국 관찰을 마치면 진행합니다 |
| 2장 | 접시 안의 얼음, 냉동실 안의 얼음은 고체. 물병 속의 물, 화분에 부어 주는 물은 액체. 천이나 빨래에서 마르며 공기로 간 물은 기체 |
| 현장 의뢰 2 | 문항이 없습니다. 준비 → 시간 보내기 → 비교를 거쳐 도구를 고르면 진행합니다 |
| 3장 | 예상 문항은 오답 처리가 없습니다. 「겨울 배관은 왜 깨질 수 있을까?」의 정답은 「얼음이 밀어서 배관이 깨져」입니다 |
| 4장 | 얼음 위에 5눈금 이상 공간이 남은 시험관이 정답입니다 |
| 현장 의뢰 4 | 정답은 「물이 얼면 부피가 커지니까 공간이 필요해」입니다 |
| 5장 | 먼저 마르는 쪽은 물이 적은 A입니다. 물은 「공기 중 수증기로」 갔습니다 |
| 6장 | 두 컵의 줄어든 물은 「수증기」로 바뀌어 공기 중으로 갔습니다 |
| 7장 | 예상 문항이라 오답 처리가 없습니다. 입구를 막아도 차가운 컵 바깥에 물방울이 생기는 것을 관찰합니다 |
| 8장 | 예상 문항이라 오답 처리가 없습니다. 차가운 병 바깥에 물방울이 생기는 것을 확인합니다 |
| 9장 | 차가운 판의 물방울이 아래로 흘러 물통에 모이면 성공입니다 |
| 10장 | 장치 시험에서 「새 물방울이 생기지 않아」면 냉각 문제, 「중간에 새는 물이 있어」면 물길 연결 문제가 정답입니다. 원인은 무작위로 정해집니다 |
| 현장 의뢰 10 | 문항이 없습니다. 물 → 수증기 → 물방울 순서로 도구를 연결하면 통과합니다 |

## 6. 수업 팁

- 자주 막히는 곳: 5장의 수증기 개념(「눈에 안 보이면 기체」로 굳기 쉽습니다), 6장의 「끓어야만 줄어든다」는 생각, 10장에서 물이 멈춘 곳을 보지 않고 고르는 경우입니다.
- 되묻기 좋은 질문
  - 줄어든 물은 어디로 갔을까? (5·6장)
  - 입구를 막았는데 컵 바깥의 물방울은 어디서 왔을까? (7장)
  - 물이 얼면 왜 통에 공간이 필요할까? (4장, 현장 의뢰 4)
- 활용: 모둠에서는 예상을 먼저 말하고 결과와 비교합니다. 전자칠판에서는 시간 관찰 장면을 함께 봅니다. 교실 연계로 차가운 용기, 받침, 모으는 컵을 만들어 실제 물 모으기를 해 볼 수 있습니다(엔딩 화면 안내).
- 교사용 설정: 설정의 「전체 해금」을 켜면 모든 실험과 의뢰를 시연할 수 있고 학생 기록은 그대로 남습니다. 「자동 관찰」을 켜면 일부 준비와 시간 관찰을 자동으로 진행합니다.

## 7. 저장과 다시 하기

- 진행은 이 브라우저와 주소의 localStorage(`water-drop-lab:v1`)에 저장됩니다. 다른 기기나 다른 브라우저로 옮겨지지 않습니다.
- 처음부터 다시 하려면 설정의 「탐험 기록 초기화」를 누르고 「기록 지우기」를 고릅니다. 소리와 움직임 줄이기 설정은 남습니다.
- 인증서의 학교·반·번호·이름은 인쇄한 뒤 손으로 적습니다. 이름은 저장하거나 전송하지 않습니다. 인증서는 「인증서 인쇄 / PDF 저장」으로 A4 한 장에 인쇄되고, 날짜와 아래쪽 제작 표기가 함께 찍힙니다.

## 8. 알려진 한계

- 교과서 단원 번호, 수업 소요 시간은 저장소에 근거가 없어 적지 못했습니다.
- 성취기준 문장은 교육과정 원문과 대조하지 않았습니다.
- 교사 검수 전입니다. 검수표(`docs/TEACHER-REVIEW-20261121.md`)에 「확인 필요」 11곳이 있습니다. 예를 들어 1장 마무리에 5장 내용인 증발 문장이 나옵니다.
- 5장 직접 조작 화면은 「바닥 속으로」를 오답으로 두고, 오답이면 같은 피드백이 나옵니다.
- 학생 난이도, 40분 수업, 저사양 태블릿, 학교 네트워크는 확인하지 않았습니다(`docs/reviews/SCORE-20261121.md`).
