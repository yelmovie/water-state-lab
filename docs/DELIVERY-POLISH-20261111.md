# 납품 완성도 개선 계획

기준 커밋은 c18c475다. 11월 11일 최종 검토에서 확인한 결함을 수정하고, 이전 사용자 요청의 실험 간소화·자유 모험 독립·악당 엔딩 조건을 회귀 검사한다.

| 순서 | 수정 | 완료 기준 |
|---|---|---|
| 1 | 온실 질문의 상단 여백 오계산 수정 | 설정 닫기·새로고침 후 같은 실험과 시계가 보이고 완료까지 진행 |
| 2 | 온실 시계와 과학 설명의 영역 분리 | 7개 화면 크기에서 대기·관찰·완료 시 겹침 없음 |
| 3 | 글자·터치·대비·키보드 조작 정리 | 주력 화면의 본문·선택지 18px, 태블릿 14px, 주요 터치 48px, 키보드 대체 경로 |
| 4 | Phaser 정리와 감소 모션 통일 | 반복 진입 노드·리스너 안정, OS 감소 모션에서 상시 tween 없음 |
| 5 | 배포 포함 파일과 사용하지 않는 import 정리 | 제거 UI의 라이브러리 제외, 기존 경로·그림·3D 동작 유지 |
| 6 | 교육 목표 메타데이터 연결 | 장별 성취기준·목표가 실제 설정 안내에 쓰이고 테스트로 검증 |
| 7 | 전체 재검증과 커밋 | 테스트·빌드·실험 완료·저장 복원·오프라인·7개 반응형 검사와 수정 후 보고서 |

기존 과학 실험의 의미, 생성 그림과 세계관, 상장 가로형, 한 번에 컵 닦기, 선택형 추가 실험을 기준으로 다듬는다. 원본 미디어는 보존한다. 실제 학생 난이도·수업 시간, 학교 태블릿 성능, iOS 인쇄와 제작 원본의 권리 승인 기록은 해당 담당자의 확인 항목이다. 재평가 점수는 검증된 수정 결과에 적용한다.

## 반영 결과

- 온실 복원, 시계 전용 배치, 주요 버튼 48px, 큰 화면 글씨, 연구노트 강조색과 키보드 분류 경로를 반영했다.
- Canvas 풀의 wheel 이벤트와 Phaser visibilitychange 누적을 해제했다. 장면 왕복 15회에서 DOM·리스너 수가 일정했다.
- 제거한 2D 보기의 코드 3개와 colorfigures 라이브러리를 납품 빌드에서 제외했다. 미사용 import를 정리했다.
- 교사용 안내에 10개 실험의 배움·성취기준을 연결했다.
- 영상 원본을 보존하고 납품본을 720p로 경량화했다. 엔딩의 ‘현장 도장 10개’ 표시는 현재 10개 실험에 맞게 ‘실험 탐구’로 수정했다.
- 기존 검토 보고서는 보존했다. 수정 후 증거와 남은 확인 항목은 `docs/reviews/RELEASE-REVIEW-20261111-2.md`, 점수는 `docs/reviews/SCORE-20261111-2.md`에 기록한다.
