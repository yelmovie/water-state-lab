# MVP 구현·검증 기록

## 판정: 조건부 배포 가능 — 내부 MVP 검토용

메인→지도→10장→코어 복구→결과까지 실제 브라우저 조작으로 완주했다. 정식 공개 배포는 하지 않았다. 전자칠판 글자 기준, 실기기·학교망, 원문 교육과정 대조, 제공 이미지의 공개 배포 권리 확인이 남아 있다. 이 조건들은 MVP 내부 플레이를 막지는 않는다.

## 확인한 것

| 검사 | 결과·증거 |
|---|---|
| 문법·빌드 | npm run check / npm run build 성공 |
| 회귀 테스트 | 13개 통과, 0개 실패 |
| 1~2장 | 물 붓기·얼음 이동·천 시간 관찰·캔 닦기, 상태·근거 기록. 잘못된 상태는 통과하지 않음 |
| 3~4장 | 영점·예상·얼리기·녹이기, 95%/40% 조건 비교와 이유 연결 |
| 5~6장 | 마우스 드래그로 직접 그린 물그림, 시간 되돌리기, 가열·관찰 핀·비교 |
| 7~8장 | 닦기·밀봉·영점·전후 측정, 증거 2개와 인과 연결, 생활 사례 |
| 9~10장 | 실패 설계→부품 이동→기울기 수정→성공. 변경 후 재시험 전 완료 차단. 기록 제출·밸브·시험·레버 |
| 확정 설계 분리 | 성공 후 공방 초안의 냉각을 꺼도 최종 화면은 기존 확정 설계를 유지 |
| 저장 | 3장 측정 후 새로고침 시 높이 예상 85·얼음 상태·측정 완료·선행 미션 복원 |
| 설정 | 움직임 줄이기를 켜고 새로고침 후 유지 확인 |
| 초기화 | 별도 확인 창을 거친 뒤 초기 상태로 복귀 |
| 인증서 | 이름 입력과 표시 확인. 실제 프린터 출력/PDF 저장은 수행하지 않음 |
| 콘솔 | 완주 과정의 error/warn 조회 0건 |
| 화면 | 1280×800 실험/엔딩, 1024×768 지도, 1920×1080 메인, 915×412 공방, 375×812 지도/공방 확인 |
| 가로 넘침 | 작은 화면의 document scrollWidth와 clientWidth 동일. 세로 스크롤 허용 |

핵심 조작은 마우스·키보드로 검증했다. 터치 실기기 동작·FPS·학교 무선망의 최초 로딩은 **NOT TESTED**다. 드래그와 공방 화살표 대체 조작을 제공한다.

## 수정한 결함

1. 성공 시험 이후 설계를 바꾸어도 완료되던 문제 → 현재/마지막 시험 signature 일치 요구.
2. 최종 화면이 수정 중인 공방 설계를 사용하던 문제 → 깊은 복사한 확정 설계로 분리.
3. 부품 이동이 과거 시험의 위치 기록도 바꾸던 문제 → 시험 시 좌표 복사.
4. localStorage getter 차단 시 초기 실행 실패 → 획득 단계부터 예외 처리.
5. 손상된 부품 저장으로 화면이 멈추던 문제 → 중첩 상태 구조 검증.
6. 예상/실제 수위선과 비커 물높이가 어긋나던 표현 → 같은 SVG 좌표계로 통합.
7. 결과를 본 뒤 예상값 변경 가능 → 얼기 이후 예상 입력 잠금.
8. 캔 닦기만으로 재발생 관찰 완료 → 닦은 뒤 시간을 진행해야 완료.

독립 읽기 전용 코드 점검을 한 번 병행했고, 1~5의 재현 경로 차단과 13개 테스트 통과를 재확인했다.

## 교육 동기·미션 가치

| 미션 | 왜 하는가 | 선택의 실제 영향 | 얻는 것 | 학습 변화·전이 |
|---|---|---|---|---|
| 1 상태 | 코어의 상태 판별 기록 복구 | 대상별 조작과 상태 판단이 기록/완료를 결정 | 상태 관찰 기록 | 겉모습이 아닌 관찰 근거로 상태 구분 |
| 2 얼음 | 냉각 배관 이상 조사 | 처음 물의 양이 얼음/공간/위험을 변경 | 전후 측정·조건 비교 | 비커의 부피 변화 관찰을 배관 단면에 적용 |
| 3 증발·끓음 | 줄어드는 물 센서 복구 | 시간·가열 조건이 자국/수위/기포를 변경 | 비교 기록 | 자국 소실과 용기 속 변화의 공통점 비교 |
| 4 응결 | 컵 밖 물방울의 출처 조사 | 확보한 증거와 인과 연결이 완료를 결정 | 응결 보고서 | 음료병 겉면 물방울에 같은 원리 적용 |
| 5 설계 | 마지막 물길 만들기 | 위치·경사·냉각이 손실점/수집 지수를 변경 | 확정 설계 | 앞의 응결 원리와 수정 설계를 코어 복구에 재사용 |

## 후속 우선순위

1. 실제 태블릿·전자칠판에서 글자·터치·최초 로딩 검증, 필요하면 큰 글씨 모드.
2. 정식 아트와 현상 애니메이션 보강. 임의의 점수보다 관찰 리플레이를 우선.
3. 원문 교육과정·이미지 권리 확인 후 외부 배포와 배포 주소 smoke test.

남겨 둔 원본 에셋·문서는 삭제하지 않았고, Git 생성/커밋/푸시·외부 공개는 하지 않았다.
