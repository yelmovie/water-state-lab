# 개념 영상 고도화 · 줄거리 세 가지 (2026-11-09)

대상: 구역마다 하나씩 뜨는 개념 영상 5편(1 물의 세 가지 모습, 2 물이 얼면, 3 사라진 물, 4 물방울(응결), 5 물의 순환).
지금 영상: 960×540, 9~15초, 무음 도형 애니메이션. 얼음은 X 상자, 얼기는 별표처럼 추상 기호이고 이름표·캐릭터·소리가 없다. 4번은 영상 대신 조작형 화면.

## 공통으로 지킬 것

- 한 편에 한 가지 생각. 장면마다 학생이 방금 한 실험 도구(게임 속 그림 그대로)를 다시 보여 주고, 그 위에서 원리를 짚는다.
- 4학년 교육과정 범위 안에서만 설명한다. 입자(분자) 모형은 쓰지 않는다. 수증기는 "눈에 보이지 않는다"를 지키고 점선 화살표로만 나타낸다.
- 이름표(물·얼음·수증기·물방울)는 해당 물체 위에, 그 물체가 나올 때 같이 뜬다. 화면 아래 자막은 지금처럼 게임 화면의 글자로 따로 보여 준다(크기 조절·읽기 쉬움).
- 끝은 결론 한 줄. 지금 `src/concept-data.js`의 문장을 그대로 쓴다.
- 1920×1080·30fps로 만들고, 태블릿용으로 1280×720 H.264(편당 2MB 안팎)로 내보낸다. 마지막 장면 WebP는 재생 실패 대체용.
- 움직임 줄이기 설정이면 영상 대신 마지막 장면과 문장만 보여 준다(지금 방식 유지).

## A. 방울이의 실험 노트 (추천 — 아이가 방금 한 실험을 방울이가 다시 해 보이니 따라가기 가장 쉬움)

- **장치·형식:** 캐릭터가 실험을 직접 한다 + 하나의 그림이 한 단계씩 자란다. 방울이가 질문을 던지고, 그릇에 붓고, 얼리고, 기다리고, 결과를 가리킨다.
- **보이는 것:** 연구 노트 종이 위에 게임 속 실제 도구 그림이 놓이고, 방울이가 옆에서 조작한다. 바뀌는 순간에 이름표와 화살표가 하나씩 붙어서, 마지막엔 한 장의 정리 그림이 된다.
- **첫 2초:** 방울이 말풍선 "물을 다른 컵에 부으면 어떻게 될까?" + 길쭉한 컵과 넓은 그릇이 나란히 놓인 화면.
- **흐름:** 질문 → 실험 재현(전·후 비교) → 바뀐 곳 확대·이름표 → 결론 한 줄 → 방울이 엄지척.
- **모습:** 크림색 연구 노트 종이, 청록 물, 황동 눈금(게임과 같은 색), Jua 글꼴 이름표.
- **소리:** 배경음 없이 행동마다 효과음(붓기·찰랑·얼음 딸깍·보글보글). 이미 있는 Kenney CC0 효과음 재사용.

| 편 | 장면 흐름(약 18~24초) |
|---|---|
| 1 물의 세 가지 모습 | 질문 → 같은 물을 길쭉한 컵·넓은 그릇에 붓기(물높이 다름, "양은 같아" 눈금) → 얼음을 옮겨도 모양 그대로 → 얼음·물·수증기 세 모습이 한 줄로 이어지며 이름표 → 결론 |
| 2 물이 얼면 | 눈금통 빨간 선 60 → 냉동고 → 꺼내니 선 위로 66 → 저울은 100g 그대로 → 같은 쭈쭈바가 부푼 모습 → 가득 찬 병은 쩍, 여유 둔 병은 괜찮음 → 결론 |
| 3 사라진 물 | 물그림 두 장(조금·많이) → 시간이 흐르며 조금 묻힌 쪽이 먼저 사라짐 → 위로 점선 화살표 "수증기(눈에 안 보여)" → 끓는 물속 기포와 표면 증발 비교 → 결론 |
| 4 물방울 | 입구 막은 차가운 컵 → 바깥에 물방울이 맺힘 → 공기 속 점선 수증기가 차가운 표면에 닿아 물방울로 → 차가운 판 아래 받이에 똑똑 → 결론 |
| 5 물의 순환 | 온실 물이 증발(점선 위로) → 냉각판에서 응결(물방울) → 받이·물통으로 모임 → 다시 온실로 흘러 한 바퀴 원이 완성 → 결론 |

## B. 보이지 않는 걸 보는 안경 (과감한 안 — 볼 수 없는 수증기를 "보이게" 하는 장치)

- **장치·형식:** 방울이가 "과학 안경"을 쓰면 화면 반쪽이 바뀐다. 왼쪽은 눈으로 보는 실제 모습, 오른쪽은 안경으로 본 수증기·물의 이동(점선·색 띠). 분할 화면이 마지막에 하나로 합쳐진다.
- **보이는 것:** 같은 장면이 둘로 나뉘어 동시에 진행돼서, "실제로는 사라진 것처럼 보이지만 사실은 공기 중으로 갔다"를 한눈에 비교한다.
- **첫 2초:** 마르는 물그림 한 장이 반으로 갈라지며, 오른쪽에만 위로 올라가는 점선이 보인다.
- **흐름:** 보이는 쪽에서 물이 사라짐 → 안경 쪽에서 어디로 갔는지 → 두 화면이 합쳐지며 결론.
- **모습:** 왼쪽은 게임 그림 그대로, 오른쪽은 짙은 청록 바탕에 밝은 점선(투시도 느낌).
- **소리:** 안경 쓸 때 "띵", 점선 이동에 바람 소리.
- **주의:** 증발·응결(3·4·5편)엔 아주 잘 맞지만 1·2편(모양·부피)엔 장치가 억지스러워진다.

## C. 연구섬 과학 뉴스 (형식이 다른 안 — 방송처럼)

- **장치·형식:** 방울이가 뉴스 진행자, 주민이 현장 기자. "오늘 연구섬에서 물이 사라지는 사건이!" → 현장 화면 → 스튜디오에서 정리.
- **보이는 것:** 뉴스 자막띠·현장 연결 화면으로 실험 장면이 나오고, 진행자가 원리를 정리한다.
- **첫 2초:** "속보" 자막띠와 방울이 진행자.
- **흐름:** 사건 제기 → 현장 실험 화면 → 진행자 해설 → 오늘의 결론.
- **모습:** 밝은 스튜디오, 자막띠, 현장 화면 테두리.
- **소리:** 짧은 뉴스 징글, 장면 전환음.
- **주의:** 재미는 크지만, 장면 전환이 많아 원리보다 형식에 눈이 갈 수 있다.
