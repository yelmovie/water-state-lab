# 전체 장 과정 개선 · 2026-11-08

대상은 본 실험 1~10장과 현재 노출되는 현장 의뢰 2·4·10장이다. 기존 진도와 완료 도장은 유지한다.

성공 조건: 준비 조건 없이 결과를 얻을 수 없음, 상태 변화에는 시간과 관찰 단계가 있음, 비교 시 바꾸는 조건과 유지하는 조건이 보임, 터치/버튼으로 진행 가능, 작은 화면에서 다음 행동을 찾을 수 있음.

확인한 핵심 수정:
- 3장: 냉각팩 즉시 얼리기와 도구가 붙은 저울 제거. 처음 측정 → 예상 → 냉동고에서 기다리기 → 꺼내 측정 → 실온에서 기다리기 → 다시 측정 → 세 기록 비교. 냉동용 통과 느슨한 덮개를 쓰는 가상 모형, 용기값을 뺀 물의 무게임을 표시.
- 10장 현장: 즉시 증발/응결 버튼을 준비 → 증발 시간 → 관찰 → 받이 배치 → 냉각 → 응결 시간 → 모으기 → 비교로 교체. 물의 출처와 남아 있는 물을 함께 표현하고 수증기는 그리지 않는다.
- 4장 한파: 아침의 얼음을 즉시 쓸 수 있는 액체 물로 부르지 않는다. 녹여 쓸 수 있는 물의 양이라는 뜻과 통별 한계를 명시한다.
- 4·6장 작은 글자와 조작 안내를 확대한다. 6~8장 준비·재관찰·증거 연결의 완료 조건을 재검증한다.

검증: 핵심 전이 회귀 테스트를 먼저 추가해 실패 확인 후 구현. 전체 기존 테스트/check/build, 10개 본 실험 및 3개 현장 의뢰의 실제 브라우저 조작, 진행 중 새로고침, 작은 화면·터치, 버튼 가림·가로 넘침 검사. 실제 아동 사용성 연구나 실제 실험 기구 측정은 이 작업의 검증 범위가 아니다.
