# 물길 탐험 3.0 설계

방울이의 부탁으로 멈춘 연구실 물길을 복구한다. 각 장은 직접 실험하고, 기록을 해석하고, 새 상황에서 써 보는 두 활동으로 이어진다. 숫자나 클릭 횟수만 늘려 시간을 끌지 않는다. 실제 학생의 활동 시간은 아직 측정하지 않았으므로 ‘몇 분 보장’으로 표시하지 않는다.

## 교육과정과 활동

성취기준 원문은 설정의 교사용 안내에 그대로 싣고, 아이에게는 현재 해결할 질문 하나와 다음 행동 하나를 보인다. 출처는 FINAL-CHECK 보고서 참조.

| 장 | 기본 실험 → 새 현장 의뢰 | 얻는 기록·다음 연결 | 성취기준 |
|---|---|---|---|
| 1 | 두 그릇 붓기·얼음 이동·젖은 천 관찰 → 물/얼음을 두 그릇에 다시 옮겨 비교 | 모양 관찰 도장 → 생활 사례 분류 | 01 |
| 2 | 실험·생활 사례를 세 상태로 분류 → 얼기·녹기·증발·응결 길에 조건 배치 | 관찰 돋보기 → 3장 이후 확대 기능 | 01 |
| 3 | 예상선·같은 물의 세 시점 높이/무게 → 사진 순서와 같은 100 g 추 | 얼기·녹기 도장 → 공간 설계 판단 | 02 |
| 4 | 서로 다른 채움 조건의 배관 비교 → 가득 찬 통과 여유 둔 통 시험 | 배관 안전 기록 → 다음 물길 해금 | 02 |
| 5 | 같은 그림의 물의 양만 달리해 세 시점 비교 → 같은 양의 물자국 넓이만 달리해 비교 | 물자국 도장 → 가열 비교 기록 | 02 |
| 6 | 무가열 대조 후 가열·관찰 → 돋보기 세 곳 이동, 줄어든 두 물의 행방 연결 | 시간 관찰 기록 → 응결 탐구 | 02 |
| 7 | 차가운/실온 밀봉 용기 비교·재닦기 → 냉각팩 A/B 교환 후 공통 조건 찾기 | 응결 증거 도장 → 설명·수집 설계 | 02 |
| 8 | 자기 증거로 설명·음료병 적용 → 찬 판과 아래 받이로 이슬받이 시험·수정 | 응결 냉각판 → 9장 공방에서 사용 | 02·03 |
| 9 | 부품 조립·실패·수정·전후 비교 → 아래로 물길 네 구간 연결 | 설계 도장·확정 장치 → 10장 실제 저장 설계 읽기 | 03 |
| 10 | 고장 관찰·증거 선택·수리·밸브·레버 → 증발/응결 조건 완성 | 복구 그림·여권 10칸·능력 문장 인증서 | 03 |

01/02/03은 [4과10-01/02/03]. 5장의 두 비교는 **서로 다른 활동**이다. 앞에서는 물의 양, 뒤에서는 펼친 넓이만 바꾼다. 수증기는 눈에 보이지 않는다. 흰 김을 수증기로 채점하지 않는다. 입자 운동·잠열 계산은 다루지 않는다. 팽창 비율·시간·수집 지수는 비교용 가상 모형이다. 실제 배관 안전 수치나 실측 수집량으로 쓰지 않는다. 가상 설계만으로 03의 실제 ‘만들기’를 충족했다고 주장하지 않고 엔딩·교사 안내에서 실물 제작으로 연결한다.

## 동기와 보상

- 시작: 새 일러스트와 ‘연구실로 가는 물길이 멈췄어’라는 사건, 방울이와 함께 고칠 역할, 10도장·5도구·복구·인증서 예고.
- 계속: 현재 장/10, 세 관찰 과정과 네 번째 현장 의뢰, 다음에 쓸 도구·기록. 방울이는 무대의 도구 가까이 이동하고 상태에 따라 도움을 준다.
- 확인: `activityReady` 또는 유효한 공방 시험 없이는 의뢰가 열리지 않는다. `fieldReady` 없이는 보상·원래 다음 액션을 실행하지 않는다. 마지막은 수리 성공+실제 시험+현장10이 함께 필요하다.
- 성취: 홀수 장 도장 연출, 구역 완료 도구·기록, 여권, 최종 복구 그림. 관찰·비교·설계를 할 수 있다는 문장을 학생이 고르면 인증서에 반영한다. 별명은 저장·전송하지 않는다.
- 재도전: 실패 지점·관찰 조건을 바로 알려 주고 같은 자리에서 수정한다. 완주 후 지도에서 실험·설계 조건을 바꿔 볼 수 있다. 고정 정답의 사진 배열·조건 연결은 반복 동기가 약하므로 실제 학생 반응을 더 확인해야 한다.

## 시각·조작 원칙

사용자 프로젝트 `1udangtangtang`의 Jua 글꼴, 버튼 계층과 가독성 규칙을 참고했다. 실제 기기에서 두 게임을 나란히 플레이한 품질 비교는 하지 않았으므로 ‘그 이상’이라는 점수는 주장하지 않는다.

지도·배경·방울이·도구는 이미지, 물높이·기포·수위·흐름은 관찰 상태를 나타내는 Canvas, 안내·기록·대체 조작은 DOM으로 나눈다. `tablet.css`의 물색·종이·황동색 토큰과 48/56px 버튼을 사용한다. Jua는 로컬 폰트이며 Phaser를 만들기 전에 최대 1.5초 로딩을 기다린다. 새 현장 Canvas의 글자는 내부 좌표 22px 이상이다. 873×580에서 540px 폭이면 약 16.5px이다. 세로 휴대폰에서는 그림이 작아지므로 18px DOM 안내·버튼 대체 조작을 사용한다.

한 번에 포인터 하나만 받고 취소·화면 전환 시 해제한다. 이동 중 매 프레임 저장하지 않고 놓았을 때 저장한다. 드래그·문지르기·선 잇기마다 같은 모형에 연결한 버튼 대안을 제공한다. 초기화는 확인 후 실행하며 소리 설정을 보존한다. 교사 시연은 학생 진행 스냅샷과 분리한다.
