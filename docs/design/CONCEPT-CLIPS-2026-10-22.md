# 스테이지 발견 영상 제작 명세

학생이 직접 실험하고 현장 의뢰까지 해결한 뒤, 개념을 다시 연결하는 9초 영상 10편이다. 먼저 정답을 보여 주지 않는다. `개념 영상 · 도장 받기` → 영상 → `발견 도장 받기` → 기존 보상·다음 활동으로 이어진다. 닫아도 진행하거나 관찰 기록을 지우지 않는다.

기존 방울이 캐릭터의 얼굴·옷·포즈 이미지를 그대로 재사용한다. 영상 오른쪽에 한 명만 배치하고, 영상 안에는 과학 도형만 그린다. 한글은 영상에 굽지 않고 화면 크기에 맞게 표시한다. 영상은 무음이며 영상 창이 열려 있는 동안 배경 음악을 멈춘다.

## 공통 샷 설계

| 구간 | 크기·각도 | 카메라 | 목적·종료 구도 |
|---|---|---|---|
| 0~3초 | 실험 도구 전체가 보이는 중경·정면 | 고정 | 비교할 두 조건을 함께 보여 주고, 같은 출발 조건에서 멈춘다. |
| 3~6초 | 도구 중심의 중근경·정면 | 천천히 3.5% 확대 | 물높이·기포·물방울·누수의 차이에 접근하고, 변화가 보이는 구도에서 멈춘다. |
| 6~9초 | 비교 전체가 보이는 중경·정면 | 1초 동안 원래 크기로 복귀 | 원인과 결과를 한 화면에 남긴다. 마지막 1초는 완전히 고정한다. |

`[CAMERA]` 고정 → 느린 확대 → 원래 비교 구도로 복귀. 각 구간에는 한 가지 움직임만 사용한다. 확대 중에도 물체가 화면 밖으로 잘리지 않는다.

`[SCENE]` 연구섬의 크림색 종이·청록색 물·황동색 눈금에 맞춘 자체 SVG 도형. 수증기 자체는 보이지 않으므로 이동 방향을 도식 화살표로만 표현한다. 액체 물방울과 물속 기포를 구별한다.

## 스테이지별 세 장면

| 단계 | 0~3초 | 3~6초 | 6~9초 |
|---|---|---|---|
| 1 | 같은 양의 물을 두 그릇에 담기 | 그릇 모양·물높이 비교 | 옮긴 얼음의 모양은 유지 |
| 2 | 얼음·물·수증기 연결 | 얼기·녹기의 조건 | 증발·응결의 방향 |
| 3 | 같은 물과 같은 무게 비교 | 얼린 물의 높이가 올라감 | 다시 녹고 무게는 유지 |
| 4 | 가득 찬 통과 여유를 둔 통 | 얼음이 차지하는 공간 증가 | 빈 공간이 있는 설계 확인 |
| 5 | 같은 그림·다른 물의 양 | 같은 양·다른 펼친 넓이 | 물이 공기 중으로 이동 |
| 6 | 끓지 않는 물의 표면 변화 | 끓는 물속의 기포 | 두 경우 모두 수증기로 변화 |
| 7 | 밀봉한 컵 바깥 물방울 | 냉각팩의 위치 바꾸기 | 컵 이름보다 차가운 조건 비교 |
| 8 | 공기 중 수증기의 방향 표시 | 차가운 판에서 물방울 생성 | 받이에 떨어지는 물 모으기 |
| 9 | 어긋난 물길에서 누수 | 받는 부품 위치 조절 | 아래로 이어진 물통에 수집 |
| 10 | 온실 물의 증발 | 냉각판에서 응결 | 물통으로 수집해 다시 연결 |

자막의 원본은 `src/concept-data.js`, 도형·시간 함수는 `scripts/concept-clips/scenes.mjs`다. 960×540, 24fps. 렌더러는 Sharp로 SVG를 RGBA로 바꾸어 FFmpeg에 직접 전달한다. 중간 프레임 파일·FFmpeg 실행 파일은 배포하지 않는다.

## 다시 제작하기

개발 도구 Sharp와 FFmpeg가 필요하다. `SHARP_PATH`를 설정하지 않으면 Node의 일반 `sharp` 모듈을 사용한다. `FFMPEG`를 설정하지 않으면 PATH의 `ffmpeg`를 사용한다. 개발 도구·임시 파일은 D:에 둔다.

```powershell
$env:TEMP="$PWD\tmp"
$env:TMP=$env:TEMP
$env:SHARP_PATH='D:\iscreammedia_sc34\1udangtangtang\node_modules\sharp'
$env:FFMPEG='D:\iscreammedia_sc34\1udangtangtang\.tools\ffmpeg\ffmpeg.exe'
npm run concepts:render
# 하나만 다시 만들 때
npm run concepts:render -- 8
```

결과: `public/assets/concepts/stage-N.mp4`, `.webm`, `.webp`. MP4는 H.264·yuv420p·faststart이며, WebM은 VP9다. 마지막 장면 WebP를 종료 화면·재생 실패 대체에 함께 쓴다. 재생 실패 시 세 설명을 모두 표시하고 다음 진행을 허용한다. 움직임 줄이기·자동재생 차단에서는 학생이 재생 버튼을 누른다.
