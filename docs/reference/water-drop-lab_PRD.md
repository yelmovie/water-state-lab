# 물방울 연구실 (Water Drop Lab) — PRD

- **Project:** 아이스크림미디어 Science World / 4학년 과학
- **Unit:** 물의 상태 변화
- **Title:** 물방울 연구실
- **Repository:** `science-world-water-drop-lab`
- **Description:** An interactive Grade 4 science game for exploring water state changes through observation, measurement, simulation, evidence-based reasoning, and iterative device design.
- **Target:** 초등학교 4학년
- **Form factor:** 태블릿 가로형 16:9 우선, 데스크톱 호환
- **Structure:** 5 Stage / 총 10 Screen
- **Backend:** 없음. 진행 상태는 브라우저 로컬 저장
- **Core engines:** Phaser 3 + DOM/SVG + Three.js
- **3D policy:** Screen 04·09 핵심 3D, Screen 01·10 경량 3D 연출, 나머지는 2D/하이브리드

## 1. 제품 목표

「물방울 연구실」은 물의 상태 변화를 객관식으로 확인하는 디지털 문제집이 아니라, 학생이 **관찰 → 예상 → 직접 조작 → 측정 → 증거 비교 → 추론 → 수정/재실험**을 반복하는 과학 시뮬레이션형 학습 게임이다.

제품의 성공 기준은 다음 질문에 답할 수 있어야 한다.

> “왜 굳이 태블릿으로 해야 하나?”

이에 대한 제품 수준의 답은 다음과 같다.

1. 학생이 물·얼음·수증기와 관련된 대상에 서로 다른 제스처를 사용한다.
2. 학생이 만든 예상선·관찰 표시·실험 기록이 다음 판단의 근거가 된다.
3. 시간 변화를 타임라인으로 압축해 비교한다.
4. 실제 실험에서 짧은 수업 시간에 반복하기 어려운 조건을 안전하게 재실험한다.
5. 3D 공간에서 장치를 배치·회전·연결하고, 결과를 본 뒤 수정한다.
6. 정답을 누르는 대신 학생의 조작 결과가 다음 상황을 변화시킨다.

## 2. 교육과정 근거

### 직접 성취기준 — 4학년

**[4과10-01]** 물이 세 가지 상태로 변할 수 있음을 알고, 우리 주변에서 예를 찾을 수 있다.

**[4과10-02]** 물이 얼 때, 얼음이 녹을 때, 물이 증발할 때와 끓을 때, 수증기가 응결할 때의 변화를 관찰할 수 있다.

**[4과10-03]** 물의 상태 변화를 이용하여 물을 얻을 수 있는 장치를 설계하고 만들 수 있다.

### 설계 원칙

- 4학년 수준에서 **관찰 가능한 변화와 현상**을 중심으로 다룬다.
- 물질 입자·분자 운동을 이용한 원인 설명을 핵심 학습 내용으로 사용하지 않는다.
- 용어 암기보다 관찰 결과와 생활 사례의 연결을 우선한다.
- [4과10-03]은 “부품을 정답 위치에 끼우기”가 아니라 **설계 → 시험 → 결과 확인 → 개선** 과정으로 구현한다.

## 3. 첨부 수업자료 벤치마킹 원칙

첨부 자료는 학습효과와 기능 아이디어를 높이기 위한 참고자료로만 사용하며, 캐릭터·레이아웃·문항·게임 규칙·표현을 그대로 복제하지 않는다.

### 참고한 학습 구조

1. **얼음 속 인형 구출 활동**
   - 문제 상황을 먼저 제시하고, 학생이 해결 방법을 선택한 뒤 변화 결과를 관찰하는 구조를 참고한다.
   - 본 게임에서는 활동 자체를 복제하지 않고 “조작 결과가 현상을 바꾸는 문제 해결형 시작”이라는 구조만 반영한다.

2. **물·얼음 상태 관찰**
   - 물과 얼음의 모양·특징과 상태 변화 관찰을 참고한다.
   - 본 게임에서는 상태별 인터페이스 자체를 다르게 하여 관찰을 행동으로 바꾼다.

3. **사라지는 물그림 활동**
   - 물로 그린 흔적이 시간에 따라 사라지는 경험을 참고한다.
   - 본 게임에서는 자유 드로잉, 물 양 조건, 타임라인 스크럽을 결합한다.

4. **증발·끓음 비교 정리**
   - 두 현상의 공통점과 차이점을 비교하는 학습 요소를 참고한다.
   - 빈칸 표를 디지털화하지 않고 학생이 남긴 관찰 표시가 비교 자료로 자동 정리되게 한다.

5. **차가운 물체 표면의 물방울 실험**
   - 처음/나중 무게 비교, 물방울 발생 관찰, 물방울 출처 추론이라는 증거 기반 탐구 구조를 참고한다.
   - 본 게임에서는 닦기·밀봉·영점·시간가속·확대관찰·증거연결 기능으로 확장한다.

6. **생활 속 상태 변화 적용 사례**
   - 수도관, 얼음틀, 차가운 컵 등 생활 맥락을 참고한다.
   - 기존 2지선다 점수형 게임 방식은 사용하지 않고 가상 실험 결과가 상황에 영향을 주게 한다.

- 교사용 해금 옵션은 공통 Science World 설정 정책에 따름

### 난이도 원칙
다음은 금지한다.

- 한 번 누르면 끝나는 활동
- OX 연속
- 객관식 2~4지선다만으로 스테이지 완료
- 같은 모양끼리 단순 끌어놓기
- 설명 영상 시청 후 정답 선택
- 실패 즉시 정답 공개

- 입자·분자 수준 원인 설명을 중심으로 한 고학년/중등 개념 선행

각 스테이지는 최소 하나 이상의 **예상/관찰/증거/수정** 단계를 포함한다.

## 5. 세계관

Science World 포털 내부에 위치한 작은 **유리 돔형 물방울 연구실**.

연구실의 중앙에는 상태 변화 실험을 제어하는 “물방울 코어”가 있으며, 사고로 5개 연구구역의 데이터가 분리되었다. 학생은 신입 연구원으로 각 연구구역을 복구한다.

완료할 때마다 다음 연구 결정이 중앙 코어에 복원된다.

- 상태 결정
- 얼음 결정
- 증발·끓음 결정
- 응결 결정
- 설계 결정

세계관은 학습을 가리는 서사가 아니라, 각 실험이 왜 필요한지 연결하는 최소한의 맥락으로 사용한다.

## 7. 5 Stage / 10 Screen

### SCREEN 01 — MAIN: 물방울 연구실
- **역할:** 진행 현황·세계관·스테이지 선택
- **렌더링:** 경량 고정 카메라 3D 디오라마
- **학생 행동:** 연구 구역 선택, 완료 상태 확인, 중앙 코어 복원 확인
- **핵심 UI:** 진행도 0/5, 연구노트, 연구 결정, 이어하기
- **완료 변화:** 각 Stage 완료 시 해당 구역의 조명·파이프·장치가 복원됨

### STAGE 1 — 세 가지 상태 판별실

#### SCREEN 02 — 같은 물, 다른 모습
- **성취기준:** [4과10-01]
- **목표:** 물·얼음·수증기와 관련된 상태를 관찰 가능한 특징과 생활 사례를 근거로 판단한다.
- **장면:** 물컵, 얼음, 젖은 천, 차가운 캔, 따뜻한 물이 있는 실험대
- **학생 행동:** 물 붓기, 얼음 이동/회전, 젖은 천 시간변화, 캔 표면 닦기, 스캐너 탐색
- **판단 구조:** 상태 판단 + 관찰 근거 선택
- **성공 조건:** 지정 사례 4개 이상에서 올바른 상태와 근거 연결
- **핵심:** 상태를 바로 고르게 하지 않고 대상별 필수 조작 후 판단 가능

### STAGE 2 — 얼음 변화 실험실

#### SCREEN 03 — 얼기 전후를 재어라
- **성취기준:** [4과10-02]
- **목표:** 물이 얼거나 얼음이 녹을 때 나타나는 변화를 관찰하고 비교한다.
- **행동:** 얼기 전 물높이 표시 → 전자저울 영점/초기값 → 얼고 난 뒤 예상선 → 냉각 → 실제 결과선/무게 → 예상과 결과 비교
- **성공 조건:** 초기·예상·결과 3개 기록 + 비교 완료
- **주의:** 공식 계산 없이 관찰 결과를 비교한다.

#### SCREEN 04 — 얼음 배관을 지켜라
- **성취기준:** [4과10-02]
- **렌더링:** **핵심 3D**
- **목표:** 물이 얼 때 관찰한 부피 변화를 생활 문제 해결에 적용한다.
- **행동:** 3D 배관 회전, 수위 조절, 냉각, 내부 확인, 다른 조건 재실험
- **성공 조건:** 최소 2개 조건 재실험 + 파손 위험이 낮은 조건을 관찰 근거와 함께 선택
- **주의:** 실제 배관 공학 압력값을 계산하지 않고 질적 비교로 처리한다.

### STAGE 3 — 물이 없어지는 실험실

#### SCREEN 05 — 물그림의 시간을 돌려라
- **성취기준:** [4과10-02]
- **목표:** 물이 증발할 때 나타나는 변화를 시간에 따라 관찰한다.
- **행동:** 자유 물그림, 물 양/붓 굵기 조절, 조건 A/B 제작, 타임라인 스크럽, 관찰 핀
- **성공 조건:** 서로 다른 두 조건을 비교하고 변화 결과를 기록
- **핵심:** 학생이 만든 흔적 자체가 관찰 대상

#### SCREEN 06 — 증발과 끓음을 비교하라
- **성취기준:** [4과10-02]
- **목표:** 증발과 끓음을 관찰하여 공통점과 차이점을 비교한다.
- **장면:** 왼쪽 비가열 물통 / 오른쪽 가열 물통
- **행동:** 가열 레버, 확대경, 수위 표시, 타임라인, 표면/내부 관찰 핀
- **관찰:** 둘 다 물이 수증기로 변함, 증발은 표면 중심, 끓음은 표면과 내부에서 변화 관찰 및 기포 확인
- **성공 조건:** 최소 3개 관찰 근거 확보 후 비교

### STAGE 4 — 물방울 사건 분석실

#### SCREEN 07 — 컵 바깥의 물을 조사하라
- **성취기준:** [4과10-02]
- **목표:** 차가운 물체 표면에서 수증기가 응결해 물방울이 되는 현상을 관찰한다.
- **행동:** 표면 닦기 → 입구 밀봉 → 전자저울 영점 → 초기값 → 시간가속 → 확대관찰 → 나중값/스냅샷
- **시각 변화:** 작은 물방울 → 커짐 → 합쳐짐 → 흘러내림
- **성공 조건:** 초기/나중 자료와 물방울 변화 스냅샷 확보

#### SCREEN 08 — 증거로 물방울을 설명하라
- **성취기준:** [4과10-02]
- **목표:** 관찰 증거를 이용해 응결 현상을 설명하고 생활 속 사례에 적용한다.
- **행동:** 증거 카드 연결, 원인-변화-결과 구조화, 생활 사례 분석
- **핵심 관계:** 공기 중 수증기 → 차가운 표면 → 물방울
- **생활 적용:** 차가운 음료 용기, 아침 풀잎의 이슬, 냄비 뚜껑 안쪽
- **성공 조건:** 핵심 증거 2개 이상을 사용해 관계 완성

### STAGE 5 — 물방울 수집 장치 공방

#### SCREEN 09 — 물을 모으는 장치를 설계하라
- **성취기준:** [4과10-03]
- **렌더링:** **핵심 3D**
- **목표:** 물의 상태 변화를 이용해 물을 얻는 장치를 설계하고 시험·개선한다.
- **부품:** 냉각판, 경사판, 깔때기, 연결관, 투명 덮개, 물통, 받침대
- **행동:** 3D 배치, 회전, 높이/경사 조절, 연결, 시험 가동, 물방울 경로 관찰, 손실 지점 확인, 재설계
- **가상 시험 지표:** 생성된 물방울, 수집된 물, 손실된 물, 수집 효율
- **주의:** 수치는 실제 장치 성능 예측값이 아니라 “가상 시험 조건”임을 명시
- **완료 조건:** 설계 → 시험 → 수정 → 재시험 과정을 거쳐 목표 조건 만족

### SCREEN 10 — FINAL: 물방울 코어 복구
- **성취기준:** [4과10-01], [4과10-02], [4과10-03] 종합
- **렌더링:** 경량 3D 연출 + DOM 결과
- **행동:** 5개 연구 결정 배치, 코어 가동, 복구 애니메이션, 결과 확인, 인증서 저장/출력
- **결과 영역:** 관찰 / 측정 / 비교 / 증거 추론 / 설계 개선
- **주의:** 10문제 객관식 종합퀴즈로 대체하지 않는다.

## 9. 공통 UI/UX 규칙

- 16:9 가로형
- safe area 6%
- 최소 터치 44px, 권장 48px 이상
- 한 화면 핵심 CTA 최대 2개
- 한국어 텍스트는 이미지에 굽지 않고 HTML/CSS/SVG로 구현
- 색상만으로 상태 구분 금지: 형태·아이콘·라벨 병행
- 이모지 중심 UI 금지
- 유아용 스티커북 느낌 금지
- 과도한 파티클 금지
- 템플릿형 카드 UI 반복 금지
- 실패 시 정답 대신 관찰 지점 강조
- 별/점수는 학습 행동보다 앞에 나오지 않음

## 10. 비주얼 방향

### 키워드
**Miniature Glass Water Laboratory**

- 투명 유리 돔
- 맑은 수로
- 반투명 얼음
- 청록·아쿠아 블루
- 크림 화이트
- 절제된 금속/금색 포인트
- 과학 장난감처럼 정교하지만 유아용으로 보이지 않는 프리미엄 3D 게임 아트

### 금지
- 눈·입 달린 물방울 캐릭터 중심
- 입자 캐릭터로 상태 변화 원인 설명
- 과학적 의미 없는 복잡한 기계
- 화면 전체가 어두운 SF 연구실
- 첨부 PPT 디자인/캐릭터/문항 구성 복제
